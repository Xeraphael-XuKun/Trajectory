## 4. 正式参数核对

| 项目 | P4设置 |
| --- | --- |
| 模块 | HISTORY.ENABLED=True、METHOD=p4；MODEL.TOKEN_TRAJECTORY=False |
| 速度 | block输出减已加完整修正的实际input；LN epsilon1e-5 |
| C0 gain | block2–12，全129token，线性零初始化，系数1 |
| 历史 | 最多三条真实Z.patch，detach，由近到远；无当前Z/投影/MLP |
| 权重 | block3固定复制；block4初始16/19、3/19；block5–12初始0.8、0.15、0.05 |
| 统计 | 余弦、相对创新、上一实际动作相对当前H强度；全部停止梯度，epsilon1e-6 |
| 门控 | block3–12，每层bias＋3系数零初始化；逐patch标量1＋0.5tanh(a)；CLS不门控 |
| loss | CE＋SoftMargin Triplet＋1×预测SmoothL1 beta1；block4–12共9层，每层平均B×128×768 |
| 梯度 | 任务训练主干/头/gain/门控；预测只训练历史logits |
| LR | 主干5e-6，头/gain/logits/门控3.5e-4 |
| coupled WD | 主干/头/gain为1e-4，logits/门控含bias为0 |
| clip | AMP unscale后，任务组整体1、logits组整体1；不先全模型clip |
| 图像/主干 | 256×128，CLIP ViT-B/16，DropPath0.1；原CLIP norm和增强 |
| 采样 | RGB/IR/Thermal；PKM/K4，逻辑64、实际192图 |
| 日程 | 60epoch cosine，100iteration warmup，起始因子0.01、最低0.002 |
| 随机与评估 | 训练seed1234、模块seed1235；每10epoch评估，最终固定epoch60 post-BN主、同权重pre-BN补充 |

ALPHA=1.0仅用于约束本方案C0系数；GATE_ETA=0.5控制动态乘数。RANK和WRITE_WEIGHT_DECAY是旧History保留项，不控制P4。P4没有P3创新方向、额外0.25、第二dense gain或预测MLP。
