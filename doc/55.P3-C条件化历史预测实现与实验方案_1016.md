## 2. 唯一结构变化

每个预测层block3–12分配独立条件参数：模态表`10×3×32`、平台表`10×2×32`。同层同条件图像共享向量；选取后为B×32，扩展为B×1×32，在该图像全部128个patch上广播。

```text
U = [sg(last_Z.patch); sg(last_Z.patch - older_Z.patch)]
hidden = GELU(W1 * U + b1 + modal_condition[layer, modality]
                            + platform_condition[layer, platform])
predicted_delta = W2 * hidden + b2
predicted_state = sg(last_Z.patch) + predicted_delta
E = current_Z.patch - sg(predicted_state)
innovation_direction = LN(E, epsilon=1e-5, affine=False)
```

block3只有一条历史，第二项旧增量为0。第一层bias和输出bias均保留，1536→32→768宽度不变。条件偏置位于第一线性层之后、GELU之前；不拼接输入、不加在输出或token上、不直接改变gain。不建立六种组合的独立表/预测器，不拆分身份头，不添加条件分类或对齐loss。

原P3两条写入保留：速度支路block2–12覆盖CLS与patch，系数1；创新支路block3–12只覆盖patch，系数0.25。速度为原block输出减实际已修正的block输入；当前Z是沿768通道的非仿射LN，epsilon1e-5。block1无观察和写入；block2只写速度并保存真实Z2.patch。历史只保存最近两条detach后的真实观察，限定在本次前向内，不保存预测历史，不跨batch。

状态、预测器、条件加法和创新LN在原P3的FP32区域计算，残差最终转换到主干dtype；原主干AMP、DropPath0.1和速度差分方式不变。

## 3. 条件语义与逐图通路

| 来源 | 内部编码与处理 |
| --- | --- |
| 模态顺序 | RGB=0、IR=1、Thermal=2；配置必须保持此顺序 |
| 平台编码 | Aerial=0、Ground=1 |
| 相机语义 | WHU-MARS合法内部相机0–6，5/6为Aerial，其余合法0–4为Ground |
| 训练 | 按原collate的模态主序拼图和拼相机向量，模态索引逐模态重复对应图像数 |
| 推理 | 原mode=1/2/3指定当前loader的RGB/IR/Thermal；当前图像camidt指定平台 |

WHU_MARS解析器对原文件相机编号执行`camid -= 1`；本实现使用解析器已经输出的内部编号，不再对camidt减1。初始化前保留真实数据camera_num=7，避免SIE关闭后camera_num被置0而丢失合法范围。SIE保持关闭。

训练processor、周期验证和do_inference原来均传camids，无需改变数据划分、样本顺序、身份标签或评估过滤规则。wrapper构造逐图条件，经backbone显式参数传入adapter，不使用模块可变的“当前条件”缓存。

query与gallery分别按自己的模态/相机提特征，不根据query/gallery角色推断平台，不读取配对属性、测试身份或检索排名。缺失相机、越界相机、浮点相机向量、数量不匹配或非法模态直接拒绝；不回退为Ground或零条件。独立调用C的backbone也必须显式提供条件。

## 4. 初始化、损失与优化

两类条件表全零初始化，不额外消耗随机数；原预测器第一层正常初始化、输出层weight/bias为0，双gain为0。条件表未冻结。初次反向由于输出层W2=0，条件表预测梯度为0；W2更新后条件表可得到梯度，不增加额外warmup或训练阶段。

预测目标仍为`sg(current_Z.patch-last_Z.patch)`；SmoothL1 beta=1，每层平均全部实际B×128×768元素，再平均block3–12十层。不按六种条件先分组等权平均。总loss仍为原CE＋batch-hard欧氏距离SoftMargin Triplet＋1×预测loss。

完整预测状态进入创新前detach，任务loss不直接更新MLP或条件表；预测loss不直接更新主干和gain。当前Z保留任务梯度。条件表加入预测组，与全部MLP参数共同裁剪；AMP unscale后任务组与预测组分别按整体L2范数1裁剪，不先全模型裁剪。

| CLIP主干 | 原设置 | 5e-6 | 1e-4 | 任务 |
| BNNeck/身份头 | 原设置 | 3.5e-4 | 1e-4 | 任务 |

新增参数1,600；模块任务参数2,072,832，预测组746,880。优化器仍为原Adam，继承原betas/eps；没有改AdamW，也没有将原Predictor bias改为WD0。

其余配置继承原P3：CLIP ViT-B/16、256×128，WHU-MARS/ALL、RGB/IR/Thermal、PKM/K4，逻辑batch64/实际192图，原增强和CLIP归一化，seed1234/模块seed1235；60epoch cosine，100iteration warmup，初始因子0.01、最低0.002，每10epoch评估。固定epoch60 post-BN为主，同checkpoint pre-BN补充，特征L2归一化，sysu评估，不开reranking。

## 5. 文件与诊断

新增`model/backbones/history_p3_c.py`，继承原P3，仅覆盖历史预测函数。原P3抽取的默认预测函数仍调用原Sequential。`model/make_model.py`负责逐图条件；`vit_pytorch.py`显式传递条件；`solver/make_optimizer.py`与`utils/history_training.py`完成LR/WD及预测裁剪组；`processor.py`增加C类型和条件表RMS诊断。

配置为`configs/history_P3_C.yml`，METHOD=p3_c；外部TOKEN_TRAJECTORY仍为False。checkpoint specification标记115，并包含模态数3、平台数2、Aerial内部相机5/6；缺失条件表、尺寸或规格不匹配会拒绝加载，不能静默将P3/A/B checkpoint当作C。

`history_epoch.jsonl`的conditioning记录模态/平台顺序、Aerial相机、参数数及两类表RMS；`history_gradients.jsonl`按modal_condition、platform_condition独立记录任务/预测梯度、更新、LR/WD。原双gain、逐层预测与copy误差、创新写入及AMP跳步诊断沿用。

工具为`tools/check_history_p3_c.py`和`tools/smoke_history_p3_c.py`；服务器脚本位于`server/history_p3_c/sensecore/`。实验配置、代码和输出与A/B各自独立。

## 6. 已完成验证与证据边界

本地真实CLIP权重与WHU-MARS的CPU检查得到`P3_C_CHECK_OK`：

- 直接核对条件加入GELU前、逐图广播、层间独立及双写入公式；确认初始条件梯度0和输出层启动后的条件梯度非零。
- 公共参数初始化和RNG与原P3一致；条件为零、非零双gain和非零W2时，完整前向、十层预测及预测loss与原P3提交2c71241逐值一致。
- 实际12图、两个身份，两次CPU Adam更新；条件表仅进入预测组，任务直接梯度0；预测反向不改变任务参数已有梯度，原bias与新增表的LR/WD正确。
- 三种模态各读取真实query和gallery图像，核对10层逐图条件；分批与置换后特征一致于FP32容差；非零表下同图改变模态或平台均影响推理。
- 非法/缺失标签拒绝、真实block速度hook、严格磁盘重载、错误条件映射规格拒绝、同权重pre/post读出和前向间历史清空均通过。

原`check_history_p3.py`同时得到`P3_CHECK_OK`与`P3_LEGACY_CHECK_OK`，确认关闭History、C0、原P3和旧HI1路径的前向/损失/优化兼容。

本地12图AMP短预检得到`P3_C_PREFLIGHT_OK`：16次尝试、7次AMP跳步、9次有效更新，训练峰值显存约2.755GiB。双gain、创新写入及两类条件表均启动，条件表任务梯度0、后续预测梯度非零；分组裁剪、参数有限性及严格磁盘重载通过。条件表最终RMS分别约6.661e-5和5.356e-5。

本地为RTX3050 Laptop、Python3.10.20、torch1.13.1+cu117、torchvision0.14.1+cu117、timm1.0.19，复用现有check-deps，未安装依赖。预检仅重复同一真实12图batch，逻辑batch4/K2，保留60epoch scheduler与真实loader的7614 iterations/epoch尺度，不是完成1epoch。

证据在工作树`work/p3_c_check/report.json`、`work/p3_regression/report.json`、`work/p3_regression/legacy_report.json`、`work/p3_c_amp/preflight_result.json`及原始日志，均不入Git。以上不能替代服务器192图预检、60epoch或完整检索；目前没有P3-C性能结果。
