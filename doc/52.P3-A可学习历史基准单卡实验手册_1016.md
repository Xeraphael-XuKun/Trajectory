## 4. 关键设置

| 项目 | P3-A设置 |
| --- | --- |
| 开关 | HISTORY.ENABLED=True，METHOD=p3_a；MODEL.TOKEN_TRAJECTORY=False |
| 观察与历史 | 真实block输出减已修正input，LN(V)；最近两条真实patch历史detach |
| 层边界 | block1零写入；block2仅全token速度；block3–12速度＋patch创新及预测loss |
| 新增a | 每层1×1×768，全1初始化，无界、无额外正则，显式历史通路专用 |
| 预测量 | (a−1)×last＋原MLP输出，损失覆盖两项 |
| 原MLP | 1536→32→768，标准GELU、原bias、末层全零初始化 |
| 写入 | 速度系数1、CLS＋patch；创新系数0.25、patch-only；原创新LN epsilon1e-5 |
| 损失 | 原CE＋SoftMargin Triplet＋1×10层SmoothL1 beta1；每层平均实际B×128×768 |
| LR | 主干5e-6；头/双gain3.5e-4；Predictor/a为1e-4 |
| coupled WD | 主干/头/速度gain/Predictor含bias为1e-4；创新gain/a为0 |
| clip | AMP unscale后，任务组整体1、Predictor＋a整体1，不先共同clip |
| 数据与图像 | 原WHU-MARS/ALL，RGB/IR/Thermal、PKM/K4，逻辑64/实际192图，256×128 |
| 日程 | 60epoch cosine，100iteration warmup，起始因子0.01、最低0.002 |
| 随机与读出 | 训练seed1234/模块seed1235；每10epoch评估；固定epoch60 post-BN主、同权重pre-BN补充 |

保留原CLIP norm、增强、DropPath0.1、共享头、sysu过滤与特征L2归一化，不开reranking。RANK/WRITE_WEIGHT_DECAY是旧History字段，A使用明确的参数族分组；不加入B的tau分母或C的条件表。
