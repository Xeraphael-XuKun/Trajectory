## 3. 第二步：正式训练60epoch

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/hi3-m2e/Trajectory/server/hi3_m2e/run_train.sh
```

脚本前台执行完整`finetune.py`，该文件按原M2-e入口调用原train.py。固定单卡，不用nohup或后台任务。保留60epoch日程、原iteration时钟、CE/Triplet、PKM192图、AMP与clip1。额外目标为`L_pred + 0.5*L_KD`，KD内部Td=2及Td²。

关键参数：α=.25、linear、patch、rank64、预测λ1、WRITE_WEIGHT_DECAY=-1（沿用WD1e-4），不是HF免衰减；新参数3.5e-4，主干5e-6；seed1234/INIT_SEED1235，CLIP norm，cudnn两项均True。

脚本保存source_commit/source_status、config_merged.yml、train.log、原train_log、history_epoch.jsonl、完整/部署checkpoint和stage_budget.json。已有本组config_merged.yml时默认拒绝再覆盖；若要重新训练另一次，应显式使用新的输出目录并单独评测，不把两次日志混在一起。

如需ACP在完整训练成功后自动运行两次末轮评估，可把下面这条作为任务启动命令，替代上面的仅训练命令（二选一，不要同时启动）：

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/hi3-m2e/Trajectory/server/hi3_m2e/run_train_and_eval.sh
```

默认输出路径下，训练成功退出才执行post/pre；任何命令失败立即停止。预检仍须事先独立完成。这个串行脚本按固定默认输出工作；改变OUTPUT_DIR的实验应分别调用训练与对应评测命令，不套用默认串行评测。
