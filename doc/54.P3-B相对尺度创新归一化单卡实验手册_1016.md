## 4. 关键参数核对

| 项目 | B设置 |
| --- | --- |
| 方法 | HISTORY.ENABLED=True、METHOD=p3_b；MODEL.TOKEN_TRAJECTORY=False |
| 真实速度 | 原block输出减已加完整修正的实际输入，当前速度任务梯度保留 |
| 速度LN | 原非仿射LN，epsilon1e-5；block2–12，全129token，系数1 |
| 历史/Predictor | 最近两条真实Z.patch，历史detach；1536→32→768，原bias、GELU、末层零初始化 |
| 创新方向 | (E−mean(E))/sqrt(var(E)+0.0625×sg(var(current_Z.patch))+1e-5) |
| 方差 | 每样本/patch沿768通道，分母768；创新方差保留梯度，只有参考方差detach |
| 固定tau | 0.25，模块固定并记录；不是残差缩放系数，不搜索其他值 |
| 创新写入 | 原0.25×innovation_gain×B方向，block3–12、patch-only，CLS无创新 |
| loss | 原CE＋SoftMargin Triplet＋1×10层SmoothL1 beta1；每层平均实际B×128×768 |
| LR | 主干5e-6；头/双gain3.5e-4；Predictor1e-4 |
| coupled WD | 主干/头/速度gain/Predictor含bias为1e-4，创新gain为0 |
| clip | AMP unscale后任务组整体1、预测组整体1，不先共同clip |
| 数据/主干 | WHU-MARS/ALL，RGB/IR/Thermal，PKM/K4，逻辑64/实际192图，CLIP ViT-B/16、256×128 |
| 日程/读出 | 60epoch cosine，100iteration warmup，起始因子0.01/最低0.002；每10epoch评估，固定epoch60 post-BN主/同权重pre-BN补充 |

训练seed1234、模块seed1235，原CLIP norm、增强、DropPath0.1、sysu与特征L2归一化保持，不开reranking。ALPHA0.25只控制创新写入；tau平方在分母。RANK/WRITE_WEIGHT_DECAY为旧History字段，不改B明确的参数分组。
