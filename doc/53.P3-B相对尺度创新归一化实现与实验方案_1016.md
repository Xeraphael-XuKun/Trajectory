## 2. 唯一结构替换

保留原P3：真实速度为原block输出减实际已修正输入；Z_l=LN(V_(l-1))，沿768通道非仿射、epsilon1e-5。原Predictor仍为逐层1536→32→768，标准GELU和原bias，历史输入为最近一条真实Z.patch及最近两条真实Z之差；历史detach，不读当前Z作为过去历史。

```text
predicted_delta = Predictor_l([sg(last); sg(old_delta)])
predicted_state = sg(last) + predicted_delta
E = current_Z.patch - sg(predicted_state)
centered_E = E - mean_channels(E)
var_E = mean_channels(centered_E ** 2)
var_Z = population_var_channels(current_Z.patch)
direction_B = centered_E / sqrt(var_E + 0.0625 * sg(var_Z) + 1e-5)
```

均值/方差对每个样本、每个patch独立沿768通道计算，方差分母768；统计张量B×128×1。参考是当前归一化速度Z.patch的实际方差，不是原始V、H、预测值、历史Z、RMS或固定常数1。

固定tau=0.25，平方后为0.0625进入分母；没有新增可训练参数或tau搜索开关。只对参考var_Z停止梯度。E的分子、均值和var_E保留任务梯度，不能detach整个分母或创新方差。方向后面不再接普通LN，也不对双分支总残差做LN。

```text
R_l.velocity = velocity_gain_l * Z_l           # block2–12，CLS＋patch，系数1
R_l.innovation = 0.25 * innovation_gain_l * direction_B
R_l = R_l.velocity + [0; R_l.innovation]        # block3–12，创新仅patch
```

创新写入系数0.25与分母tau=0.25是两个不同作用的固定数；不能再把tau乘到写入或速度路径。

单token方向RMS为`sqrt(var_E/(var_E+tau²*sg(var_Z)+epsilon))`。小创新可保持小幅度，大创新趋近原LN尺度；常数或零创新的中心化输出为零，不添加回退方向。该尺度性质不限制密集gain，不是相对H的残差上限，也不保证检索性能。

## 3. 保留的层边界、损失和梯度

| block | 观察/历史 | 写入与监督 |
| --- | --- | --- |
| 1 | 无Z1，不构造虚假零观察量 | 无写入、无预测loss |
| 2 | Z2来自V1；结束保存真实Z2.patch | 仅原C0速度，全token；不调用Predictor |
| 3 | 读取Z2；旧增量为0 | 速度＋B创新，首个预测loss |
| 4–12 | 最近两条真实patch观察及其差，历史detach | 速度＋B创新、预测loss |

历史仅存在于单次图像前向，不缓存预测量，不跨batch或图像。CLS仍仅速度写入。状态、预测及B的均值/方差/分母在原P3的FP32分支计算，残差最后转回主干dtype；原block的AMP、attention、MLP、DropPath和主干速度差分方式不改。

L_pred仍监督原Predictor输出与`sg(current_Z.patch-last)`，不用direction_B作为目标；SmoothL1 beta1，每层平均实际B×128×768，再平均block3–12共10层。总loss仍为原CE＋batch-hard欧氏距离SoftMargin Triplet＋1×L_pred。无额外loss、预测warmup或训练阶段。

任务组为主干、BNNeck/分类头和两套gain，预测组仍只有MLP。任务loss对Predictor直接梯度为0，预测loss不直接更新主干/gain；当前Z经E保留任务梯度，仅参考方差旁路停止梯度。改变写入后后续状态和预测目标会随训练变化，不能说完整训练轨迹中的Predictor与原P3不变。

## 5. 接入与诊断

HistoryP3BAdapter继承P3，仅覆盖创新方向归一化；原P3只抽出归一化调用方法，其p3分支仍调用原F.layer_norm。主干循环、数据、原loss、梯度分组和训练入口不改。

配置configs/history_P3_B.yml显式METHOD=p3_b、外部TOKEN_TRAJECTORY=False。tau/epsilon固定在B模块，并写入checkpoint specification；方法标记114，与原P3的103和A的113区分，不能静默把原P3/A checkpoint当B加载。它们不是新的可训练参数。

history_epoch.jsonl增加innovation_normalization，记录relative_variance、tau0.25、epsilon1e-5及current_z_patch_variance_detached。原normalized_innovation_rms记录实际B方向RMS，不再要求接近1；gain/双分支修正、PG、copy_mse与优化梯度诊断继承P3。

核心文件为model/backbones/history_p3_b.py、history_p3.py、model/make_model.py、solver/make_optimizer.py、processor/processor.py。工具为tools/check_history_p3_b.py与tools/smoke_history_p3_b.py；独立服务器脚本在server/history_p3_b/sensecore/。

## 6. 验证证据与边界

真实CLIP权重与WHU-MARS小批次CPU检查得到P3_B_CHECK_OK：

- 非单位且逐token不同尺度的参考方差核对分母、方向RMS公式；零/常数创新输出有限且为零。
- 独立创新/参考输入的求导验证仅参考方差detach；创新均值和创新方差均参与正确任务导数，区别于错误的整分母detach。
- 原P3非零双分支/非零Predictor下完整前向、预测loss及优化规则与2c71241逐值一致，公共参数初始化和RNG保持。
- B在局部tau0时的完整eval前向/预测loss与原P3在FP32容差内一致，最大前向绝对差为4.053e-06；tau0只作数值验证，不是正式候选配置。
- B全零gain时基础参数、输出和RNG与baseline一致；同时确认创新gain启动导数一般不同于原P3，不能将初始前向一致误写成训练等价。
- 真实速度hook、10层loss、两次真实CPU Adam更新、745,280预测参数与LR/WD/分组clip、主干/预测梯度隔离检查通过。
- 严格磁盘重载、错误tau规格拒错、同权重pre/post读出、前向间状态清空，以及旧HI1非零gain前向/loss/优化器兼容检查通过。

本地12图AMP预检16次尝试、7次AMP跳步、9次有效更新，训练峰值显存约2.842GiB，得到P3_B_PREFLIGHT_OK。

本地AMP使用RTX3050 Laptop、Python3.10.20、torch1.13.1+cu117、torchvision0.14.1+cu117、timm1.0.19，复用现有work/check-deps、未安装新依赖。逻辑batch4/K2、同一真实12图batch重复16次，保留60epoch日程和真实sampler iteration尺度。双gain/创新写入启动、方向RMS有限、梯度隔离/分组clip、参数有限性与严格磁盘重载均通过。

证据在独立工作树work/p3_b_check/report.json、legacy_report.json及work/p3_b_amp_preflight/preflight_result.json和原始日志。产物不入Git。局部检查不能替代单A800/192图预检、60epoch或完整检索；B尚无性能结果。

## 7. 对比和归档

B只检验相对尺度创新归一化，不叠加A的历史系数、C的条件表，不增加tau搜索或阶段训练。创新变小、PG变化或写入活跃不等于检索改善，正式仍固定epoch60主/辅读出与原P3比较。

本方案、手册及后续结果固定归入`1016_历史创新P3三种改版`批次，文件名带P3-B，输出与A/C及旧P3保持独立。
