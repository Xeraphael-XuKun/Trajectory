## 2. 方法定义

模块与`b44e69c`首轮History代码一致。固定768×64正交投影；每图前向重建历史，仅保留最近两个detach状态与上一层detach修正。当前状态保留任务梯度。

对每一层与token分别计算：

`S_l = LN(H_l) P`

`pred_delta_l = Predictor_l([sg(S_{l-1}); sg(S_{l-1})-sg(S_{l-2})])`

`E_l = S_l - (sg(S_{l-1}) + pred_delta_l)`

`D_l = Anchor_l(E_l) + Corrector_l([S_l; E_l; sg(R_{l-1})P])`

`R_l = 0.25 * G_l * D_l`

原block仍执行`Block_l(H_l+R_l)`，全部12个block前写入；首层无预测历史，采用`E_1=S_1`，第二层旧增量置零。

CLS读取自己的状态、历史与上层CLS修正；不是把patch修正平均后加给CLS。CLS与patch共享各层Predictor/Anchor/Corrector及投影P，拥有独立零初始化gain。原patch gain为[12,1,128,768]，新增CLS gain为[12,1,1,768]；比HI3增加9,216个参数，总新增可训练参数2,662,528。

预测辅助损失**仍只监督128个patch**，监督层2—12每步全部计算；beta1 SmoothL1先在batch/token/channel平均，再层平均。没有CLS预测loss，不改变分母。共享predictor会受patch预测监督间接影响，CLS gain只从身份目标获得梯度。

`L = L_CE + L_Triplet + 1.0*L_pred`

从epoch1使用固定权重，没有额外warmup、动态系数、残差归一化或范数限制。
