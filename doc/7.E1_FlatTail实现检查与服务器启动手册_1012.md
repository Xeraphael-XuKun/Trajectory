## 1. 实际改动与设置

`configs/r2_m5_flat_tail.yml`完整复制原M5学生checkpoint的实际合并配置。父配置保存为 `configs/r2_m5_parent_actual.yml`，四个复用工件的已核验指纹保存为 `configs/r2_m5_parent_artifacts.json`。允许的差异为R2实验标识、输出路径、同实验恢复路径及明确的资源路径映射；路径映射后工件必须保持原指纹，其他训练设置变更会被拒绝。

FlatTail先对原cosine/0.07 logits再除Td=2，保留训练真身份概率aT，把其他499类概率变为(1−aT)/499；整个目标detach。优化项为batch平均KL(q||pS)，函数只乘一次Td²，processor外层只乘一次0.5。未追加原full KD、硬文本CE、可靠性筛选或OneSided门控。原full KD仅每50步作为无梯度诊断输出。

原教师forward、同增强张量、文本/投影、C0公式、主CE/Triplet、采样、augmentation、Adam、裁剪、调度和评测路径保留。`R2.ENABLED=False`仍调用原kd_kl，不读取新增工件清单，不构造新模块。旧M2 VARIANT及VERSION保留；E1身份放入独立R2配置和checkpoint元数据。

| 项目 | 保留值 |
|---|---|
| 学生初始化 | 原CLIP + 原seed下C0 gain、分类头和BN初始化；不是旧学生epoch60续训 |
| 学生预算 | 60epoch，seed1234，batch64，PKM NUM_INSTANCE4 |
| 优化 | Adam，预训练LR5e-6，新参数LR3.5e-4，WD1e-4，warmup100iteration，原cosine，clip1.0 |
| KD | 基础温度0.07，Td2，外层系数0.5 |
| 教师/prompt | 复用原工件，本次优化步均0 |
| 评测/保存 | 原每10epoch评测；原checkpoint period60，不选中途best |
| 主结果 | epoch60、post-BN、ALL、sysu、L2归一化、无rerank；pre-BN同权重补充 |

训练每50步记录teacher/FlatTail熵、aT/aS、改写argmax比例、二元项、均匀尾部项、实际加权尾部项、原full KD诊断、含Td²的实际KD和乘0.5后的KD、CE/Triplet、iteration/实际update/AMP跳步。日志是该步batch统计，不能直接当作全epoch平均。

FlatTail可能把教师原来预测错误的样本改为真身份最大概率，因此不是保留了教师全部top1决策。实验是机制对照，尚无结果，不预称为改进。
