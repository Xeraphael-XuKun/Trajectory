## 2. P2的精确计算

公式层号1–12，对应源码layer0–11。`H_l`是本层写入前状态。新增分支采用FP32，最终残差转换为主干token dtype；原block的attention、MLP、LN和DropPath保持。

1. **修正前状态**：`S_l = LN(H_l.patch) P`。LN仅沿768通道、非仿射、epsilon1e-5；P为768×64固定正交buffer，全部层共享。
2. **首层边界**：block1只计算并缓存`S_1.detach()`；R1=0，Q1=0，不运行Predictor或方向网络，也不分配首层闲置网络/gain。
3. **只读历史预测**：block2–12的Predictor为`128→64→64`、GELU、两层有bias；输入`[sg(S_(l-1)); sg(S_(l-1)-S_(l-2))]`，第二层旧增量为零。
4. **创新量**：`S_hat_l = sg(S_(l-1)) + Predictor_l(...)`，`E_l = S_l - sg(S_hat_l)`。当前S保留任务梯度，预测结果进入任务路径前detach。
5. **上一动作**：`Q_(l-1) = sg(R_(l-1).patch) P`。读取上一层真正写回主干、完成dtype转换后的残差，不读未缩放方向，不额外归一化Q。
6. **低维融合**：`T_l = Linear_(192→64)([S_l;E_l;Q_(l-1)])`，`Z_l = E_l + GELU(T_l)`。E的显式直连必须保留，S/E/Q及拼接输入不增加LN。
7. **空间混合**：按PatchEmbed的高先、宽后顺序，将`[B,128,64]`恢复为`[B,64,16,8]`，计算 `Z_grid' = Z_grid + 0.5*(DWConv3(Z_grid) + DWConv5(Z_grid))`。两支并行读取同一输入，不串联，不插入额外激活、LN或池化。
8. **升维与写入**：恢复token排列，`D_l = Linear_(64→768)(GELU(Z_l'))`，`R_l.patch = 0.25 G_l ⊙ LN(D_l)`，CLS残差为0，执行原`Block_l(H_l+R_l)`。升维后不加输出激活，不额外使用P1的Anchor、第二套gain或C0。
9. **更新历史**：缓存修正前S的detach副本及实际R的detach投影，只保留最近两层状态；每次图像前向清空，无跨图像/batch缓存。

正式网格固定16×8。模块从实际骨干grid_h/grid_w构建，配置要求256×128与16×16 stride；网格尺寸也写入checkpoint规格，避免同patch总数、不同长宽的静默混用。

## 3. 初始化、梯度及参数量

新模块在CLIP加载后，通过隔离CPU RNG的`fork_rng(devices=[])`、INIT_SEED=1235构建。第一个随机操作与P1完全相同，为标准高斯768×64矩阵的薄QR。已从P1已提交源码验证P与全部Predictor初值逐元素一致；不依赖P1训练产物。

gain全零；Predictor最后一层权重/bias全零；其余线性层按输入维度均匀初始化`±1/sqrt(in_features)`。两个depthwise卷积均无bias，groups=64，stride/dilation=1，3×3 padding1、5×5 padding2，核全零。零卷积只使空间子路径初始为恒等，不使整个方向为零；融合和升维线性层均保持非零初始化。

| 参数族 | 层集合 | 参数量 | 直接梯度 |
| --- | --- | ---: | --- |
| gain `[11,1,128,768]` | 2–12 | 1,081,344 | 身份任务 |
| Predictor | 2–12 | 136,576 | 预测loss |
| 低维融合192→64 | 2–12 | 135,872 | 身份任务 |
| 3×3与5×5深度卷积 | 2–12 | 23,936 | 身份任务 |
| 升维64→768 | 2–12 | 549,120 | 身份任务 |
| 总新增可训练参数 |  | **1,926,848** | 不含P的49,152个固定元素 |

gain为零时方向网络任务梯度暂时为零，但gain有启动梯度；gain更新后，融合、两支卷积和升维网络均能获得任务梯度。预测loss不直接更新这些方向参数或主干；身份loss不直接更新Predictor。历史S、Q和预测参照detach，当前S/E的任务路径保留。

## 4. 训练、损失和推理协议

`L = CE + Triplet + 1*L_pred`。原CE不做label smoothing，Triplet保留batch-hard欧氏距离和SoftMarginLoss，不额外归一化特征或启用0.3 hinge margin。

`L_pred`使用beta1的SmoothL1，监督`predicted_delta`对`sg(S_l-S_(l-1))`。每层对实际图像batch×128patch×64通道求mean，再对block2–12的11层求mean。首层和CLS不计入分母；训练开始即启用，无新增warmup。

| 参数族 | 峰值学习率 | coupled WD |
| --- | ---: | ---: |
| CLIP预训练主干 | 5e-6 | 1e-4 |
| BNNeck和分类头 | 3.5e-4 | 1e-4 |
| P2 gain | 3.5e-4 | 0 |
| 融合、升维、两支深度卷积 | 1e-4 | 0 |
| Predictor含bias | 1e-4 | 1e-4 |

使用原Adam，不改AdamW，不覆盖原betas/eps；bias学习率系数1。AMP backward后先unscale，再将任务组整体与预测组整体分别按L2总范数1裁剪，两组不重叠且覆盖全部可训练参数；不先做全模型clip。WD仍由Adam内部加入。

正式训练：共享CLIP ViT-B/16，256×128，12block/768维，RGB/IR/Thermal，原PKM/K4，逻辑batch64/实际192图；原CLIP norm与增强，DropPath0.1；60epoch cosine，100iteration warmup、起始0.01、最低0.002；训练seed1234、模块初始化seed1235。无教师、文本或模态专属参数，无额外主干前向或残差预算。

已解析比较P1/P2完整YAML：除`HISTORY.METHOD`和独立OUTPUT_DIR外，训练设置一致。P2推理保留固定投影、历史预测、空间方向与写入，但不构造预测目标或loss；同一epoch60权重以768维post-BN为主、pre-BN为补充，原检索归一化/相机过滤规则和不使用reranking保持。

## 5. 已执行检查及其范围

CPU检查使用Python3.10.20、torch1.13.1+cu117及本地真实CLIP权重/WHU-MARS数据，已获得`P2_CHECK_OK`：

- 小型非方形网格手算，验证低维E直连、patch顺序、并行3×3/5×5、零核恒等及非零核空间变化，CLS始终不写入。
- 验证历史/Q/预测参照梯度边界、当前状态梯度和11层SmoothL1平均；首层无闲置网络。
