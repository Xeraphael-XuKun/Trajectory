## 1. 当前判断与问题

HI3为上一轮最好配置，但最终修正量接近零，不能据其分数宣称最终检索依赖持续的历史修正。预测器优于copy也不等于预测目标有利于身份检索。

当前线性形式为`r=αG⊙D`。G零初始化时，身份损失对方向网络的梯度被G挡住；G较小时，方向网络的梯度也可能较弱。若方向网络同时收缩，G的数据梯度也会削弱。当前Adam、全局clip与weight decay可能共同影响这一过程，但需要对照确认。

将α由0.25改为1，在相同G和D下使修正增大4倍；它改变优化尺度，但不保证Adam更新增大4倍，也不能消除零增益时方向网络的初始零身份梯度。线性G本来无界，α=1不是新增表达能力的证明。

## 3. 保持日程的短程运行

当前scheduler使用`MAX_EPOCHS × len(train_loader)`确定余弦周期，不能通过把MAX_EPOCHS改成5来模拟正式训练的前5epoch。

本次增加独立的`HISTORY.STOP_AFTER_EPOCH`：

- 0：完整执行MAX_EPOCHS，兼容原HI配置。
- 5：按60epoch日程训练到第5epoch，保存`transformer_5.pth`、`history_stop.json`后退出。
- 10：按60epoch日程训练到第10epoch；启动脚本使用新的e10目录，**从相同初始化重新开始**。

当前只保存模型权重，不保存完整optimizer/scaler/随机数/数据加载器续训状态。为避免伪称精确断点恢复，e5→e10采用新目录重新运行前10epoch，不接着加载transformer_5.pth训练。正式HF也从初始化完整训练。

短程前5epoch只检查初期过程。若结果不明确，可只对有信息量的两组运行前10epoch；不能凭5epoch宣称长期退化已解决。

## 4. 新增诊断的实现与解释

### 4.1 记录文件

| 文件 | 内容与时间点 |
| --- | --- |
| history_optimizer_initial.json | 初始各参数族RMS、有效gain RMS、实际优化器LR/WD、日程长度与停止点 |
| history_gradients.jsonl | 抽样batch中各损失梯度、全局裁剪前范数、裁剪前后分支梯度、Adam衰减项、是否AMP跳步 |
| history_epoch.jsonl | 原预测/CE/Triplet/逐层修正诊断，并增加epoch末参数族统计 |
| history_stop.json | 正常停止的epoch、60epoch日程、权重名、未保存续训状态的明确标记 |

参数族为gain、Predictor、Anchor、Corrector；HF3增加cls_gain。初始快照中的LR可能处于warmup起点，不是把新模块BASE_LR误设成主干LR。

### 4.2 梯度字段

| 字段 | 含义 |
| --- | --- |
| identity_grad_norm | 原CE＋Triplet对该参数族的梯度范数 |
| prediction_raw_grad_norm | 未乘λ的预测项梯度范数 |
| prediction_weighted_grad_norm | 乘λ后的预测项梯度范数；HF2为0 |
| data_grad_preclip_norm | 正式总loss backward并unscale后的分支梯度 |
| global_grad_preclip_norm | 全模型正式clip返回的裁剪前范数 |
| data_grad_postclip_norm | 正式全局clip之后的分支数据梯度 |
| decay_term_norm | Adam将加入的WD·parameter范数，仅对grad非None的参数计入 |
| adam_input_grad_norm | clip后的数据梯度＋衰减项的合成范数，不是最终Adam参数更新范数 |
| decay_to_data_norm_ratio | 衰减项范数/clip后数据梯度范数；分母0时null，不记成无穷或0 |
| amp_skipped | 正式GradScaler是否跳过本次更新 |

梯度抽样的`parameters`记录在本次优化器更新前，epoch汇总中的参数统计在该epoch全部更新之后；不能错位相减。参数范数使用float64累加，减少极小参数平方下溢。非有限梯度记录null，并保留AMP跳步标记；分析范数时应过滤溢出/跳步样本，不把null视为零。

辅助梯度测量复用同一forward计算图，以与正式GradScaler相同的尺度调用`autograd.grad`，之后除回scale；不向`.grad`写入，不二次forward、不额外采样DropPath、不修改loss。正式backward、全局clip和optimizer.step仍只执行原有一次。

抽样的梯度族范数不能直接等同最终参数更新。尤其不能仅依据“衰减/数据>1”宣布衰减是根因；需结合2×2对照和修正量变化。

### 4.3 为什么不能只看G

对比不同α必须比较`effective_rms=RMS(αG)`和实际写入比例。α=1时G变小，可能只是尺度重新分配，并不必然是退化；反之G变大但D收缩，也不能证明分支有效。

不设置强迫残差不为零的下限，不新增“增大残差”的loss，不以最大修正量自动选组。

## 5. 可选离线历史依赖检查

`tools/probe_history_dependence.py`可使用已有HI权重或HD阶段保存的权重，无需训练：

1. 默认从query中每个模态×空地视角选择8个不同身份，每身份一张图。
2. 同一次正常forward捕获patch预测器输入、输出和各层状态。
3. 固定当前样本target，比较真实历史与同模态、同视角的跨身份循环置换历史；不改变主干的正常forward，不把反事实预测写回模型。
4. 同时报告copy以及“其他身份的逐patch位置平均变化”参照。后者是留一身份均值，仅作诊断，不是可部署预测器，也不是训练得到的对照模型。

它回答小样本中的历史依赖性，不能替代完整检索，也不能凭置换后误差变化就宣称身份信息增强。置换包含不同人物及可能不同相机，结果受样本选择影响；默认8身份不是完整数据集统计。

这项工具不是HD启动门槛，也不自动修改α或λ。

## 6. HD后的决策规则

| 观测 | 优先判断与动作 |
| --- | --- |
| HD1改善、HD2变化小 | α可能重要，优先考虑α=1 |
| HD2改善、HD1仍退化 | 优先调整写入通道衰减 |
| 只有HD3改善 | 两因素可能需要共同作用，延长观察 |
| 多组改善 | 优先考虑训练正常、修正可测且改动较少的组，不按最大残差选优 |
| 四组仍收缩 | 暂不盲目跑满60epoch；再检查增益粒度、方向参数化等 |
| 修正保住但身份训练明显恶化 | 不视为成功；可能只是放大了无益写入 |

此前tanh增益没有明显饱和，因此本轮不新增tanh对照。CLS扩展先留到HF阶段，不与退化诊断一起改变。
