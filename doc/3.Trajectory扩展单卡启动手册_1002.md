# Trajectory 扩展单卡启动手册（2026-10-02）

## 1. 固定边界

本轮只使用llmpar+CLIP norm、benchmark=True、deterministic=True。每个入口使用CUDA_VISIBLE_DEVICES=0、WORLD_SIZE=1，独立前台训练60 epoch，再加载同一transformer_60.pth测试pre-BN和post-BN。全部关键训练参数已明确写入七份独立YAML，详见 [实验方案](2.Trajectory五版扩展实验方案_1002.md)。

当前仓库的完整训练入口是train.py，没有finetune.py；因此遵循前台执行完整训练的约定，直接调用现有train.py，不新增同名包装或改变训练路径。脚本不会安装环境、上传代码或启动远程任务。

## 5. 输出、重试与路径覆盖

每组输出为上述父目录下的`T1_seed1234`等独立目录：训练日志和transformer_60.pth位于根目录，独立测试日志位于eval_preBN/、eval_postBN/。脚本使用set -euo pipefail，训练或pre-BN测试失败时停止后续步骤；不自动重试。

任何已有输出目录都会触发停止，避免覆盖checkpoint。重跑使用新的独立输出目录，例如：

```bash
TRAJECTORY_RUN_DIR=/mnt/cache/wanghanzhi/XK/Trajectory/logs/trajectory_extensions_1002/T1_seed1234_retry1 \
  bash /mnt/cache/wanghanzhi/XK/Trajectory/server/extensions/sensecore/run_T1.sh
```

```bash
TRAJECTORY_RUN_DIR=/root/autodl-tmp/XK/Trajectory_runs/autodl/trajectory_extensions_1002/T1_seed1234_retry1 \
  bash /root/autodl-tmp/XK/Trajectory/server/extensions/autodl/run_T1.sh
```

路径覆盖变量在全部14个脚本中一致，均有绝对路径默认值：

| 变量 | 用途 |
|---|---|
| TRAJECTORY_CODE_DIR | 实际源码目录 |
| LLMPAR_PYTHON | 实际llmpar Python绝对路径 |
| TRAJECTORY_DATA_ROOT | WHU-MARS父目录 |
| TRAJECTORY_CLIP_WEIGHT | ViT-B-16.pt绝对路径 |
| TRAJECTORY_RUN_DIR | 本次实验独立输出目录 |

只改变输出目录中的seed字样不会改变随机种子。需要多seed确认时，应复制对应YAML修改SOLVER.SEED，并令独立入口指向该配置和新输出目录，保留首轮配置不变。
