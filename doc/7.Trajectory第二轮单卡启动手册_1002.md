# Trajectory 第二轮单卡启动手册（2026-10-02）

## 1. 运行方式

每组独立前台训练60epoch，随后重新加载同一`transformer_60.pth`：先post-BN主测试，再pre-BN补充。`CUDA_VISIBLE_DEVICES=0`、`WORLD_SIZE=1`；一组使用一个独立单卡任务。训练参数全部位于对应YAML，见[四组方案与隔离说明](6.Trajectory第二轮四组方案与隔离说明_1002.md)。

仓库实际完整训练入口是`train.py`，没有`finetune.py`，因此脚本直接执行`train.py`，不新增包装、不强制预检、不自动恢复。输出目录存在时停止，避免覆盖实验。不要同时在同一张GPU启动四组。

## 2. 路径

沿用第一轮已配置的Trajectory独立项目路径；这是脚本默认值，不表示本次登录服务器核实过。项目级通用约定中的WHU-Baseline目录与这里的Trajectory实验目录不同；若本轮实际代码部署在WHU-Baseline，使用下方变量明确指定，不需要复制成四个项目。

| 内容 | SenseCore | AutoDL |
|---|---|---|
| 代码 | /mnt/cache/wanghanzhi/XK/Trajectory | /root/autodl-tmp/XK/Trajectory |
| Python | /mnt/cache/wanghanzhi/envs/llmpar/bin/python3 | /root/autodl-tmp/envs/llmpar/bin/python3 |
| 数据父目录 | /mnt/cache/wanghanzhi/Datasets | /root/autodl-tmp |
| CLIP权重 | /mnt/cache/wanghanzhi/Datasets/ViT-B-16.pt | /root/autodl-tmp/ViT-B-16.pt |
| 输出父目录 | /mnt/cache/wanghanzhi/XK/Trajectory/logs/trajectory_refinements_1002 | /root/autodl-tmp/XK/Trajectory_runs/autodl/trajectory_refinements_1002 |

数据父目录下应有`WHU-MARS`；不要把`DATASETS.ROOT_DIR`指定为WHU-MARS本身。保持既有llmpar环境，不安装或替换依赖。代码部署应包含本轮全部变更；不要改动其他正在训练任务使用的代码。

## 5. 结果检查

每组应生成训练日志、`transformer_60.pth`、`eval_postBN`和`eval_preBN`两个独立测试日志。训练中验证采用post-BN；epoch60验证应与独立post-BN测试对应。R1—R4不要使用旧C/T配置测试，方法标识不匹配会直接报错。

若训练成功而补测中断，不要重跑整套训练脚本；使用对应R组配置、原epoch60权重和新的评测输出目录单独运行`test.py`。例如R3的post-BN补测：

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 /mnt/cache/wanghanzhi/envs/llmpar/bin/python3 -u \
  /mnt/cache/wanghanzhi/XK/Trajectory/test.py \
  --config_file /mnt/cache/wanghanzhi/XK/Trajectory/configs/trajectory_R3.yml \
  MODEL.PRETRAIN_PATH /mnt/cache/wanghanzhi/Datasets/ViT-B-16.pt \
  MODEL.TEXT_CLIP_PATH /mnt/cache/wanghanzhi/Datasets/ViT-B-16.pt \
  DATASETS.ROOT_DIR /mnt/cache/wanghanzhi/Datasets \
  TEST.WEIGHT /mnt/cache/wanghanzhi/XK/Trajectory/logs/trajectory_refinements_1002/R3_seed1234/transformer_60.pth \
  TEST.NECK_FEAT after \
  OUTPUT_DIR /mnt/cache/wanghanzhi/XK/Trajectory/logs/trajectory_refinements_1002/R3_seed1234/eval_postBN_retry1
```

pre-BN补测将`after`改为`before`，并将输出改为新的`eval_preBN_retry1`。保留失败日志和已有测试结果。
