## 方法与已正确部分

阶段 A 使用原始冻结 CLIP train 特征学习每个训练身份的四个连续 token；四个 D 槽在四个身份槽之前。阶段 B 固定身份 token，将同一组 `C_l` 放入文本第2—12层输入，并通过共享 Q/K/V/O 投影调制对应视觉 C0 修正。乘子 `1+0.25*tanh(...)` 保持修正符号，视觉序列仍为129个 token。身份、光谱、平台标签不进入视觉控制器。

原实现已经正确保留了文本 causal mask、一次位置 embedding、实际 EOT 读出、十一层输入状态初始化、零 WO、实际修正后 block 输入的速度定义，以及每个唯一 batch 身份只编码一次。原 CE 无 smoothing、soft-margin Triplet 和 C0 学习率设置也已正确；没有沿用 M2-2 的 CE 配置错误结论。

## 工程细化决定

身份 token、锚点和初始深层状态合并在一个 `deep_slot_prompt_bank.pt` 工件，避免三份文件来自不同阶段。`M2.TEXT_BANK`、`ID_PROMPT_WEIGHT`、`DEEP_CONTEXT_INIT` 在本配置指向同一个 bundle，后两项非空且不一致时明确报错。这是序列化组织选择，不改变数学目标。旧 feature cache/prompt bank 必须重建。

教师确定性 resize 统一沿用项目评测的 bilinear，并明确记录；旧缓存的 bicubic 未记录在来源中。本次不将“文档未指定插值方式”误称为已证明旧教师数学无效。

学生每个保存 epoch 输出 `transformer_E.pth`（模型+方法/全配置/来源+optimizer/scheduler/scaler/RNG+计数）和 `transformer_E_student.pth`（保留 C 和控制器的部署权重）。M2 关闭时原裸 state_dict 保存方式不变。epoch 边界恢复使用 `M2.RESUME`；不宣称 batch 中断精确恢复或 prompt 阶段中途恢复。
