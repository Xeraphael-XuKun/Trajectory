## 1. 问题、假设与边界

## 2. 具体计算

采用从 1 开始的层编号。`H_l` 为进入第 l 个 block、加入本方案修正之前的 token。以下先定义 HI1/HI0 的 patch-only 路径，HI2/HI3 的差异见后文。

1. `S_l = LN(H_l_patch) P`。P 是各层共享、固定的正交列投影，尺寸 768×64，随 checkpoint 保存。
2. 缓存最近两个 `sg(S)`；第一层无历史，第二层旧增量置零。历史只属于本图像的一次前向，不跨 batch 或图像复用。
3. `pred_delta_l = Predictor_l([sg(S_{l-1}); sg(S_{l-1})-sg(S_{l-2})])`。
4. `E_l = S_l - (sg(S_{l-1}) + pred_delta_l)`。第一层直接令 `E_1=S_1`。
5. `previous_r = sg(R_{l-1,patch}) P`；第一层置零。这里没有给 R 额外做 LayerNorm。
6. `D_l = Anchor_l(E_l) + Corrector_l([S_l; E_l; previous_r])`。
7. `R_l_patch = 0.25 * tanh(G_l) * D_l`，CLS 对应修正恒为零。
8. 原 block 接收 `H_l + [0; R_l_patch]`；原 attention、MLP、DropPath 全部保留，不重写 block。

每一层都写入，包括首层；只有第 2—12 层存在预测目标。它不是 C0 的第 2—12 层速度注入，也不使用 C0 的速度或加速度公式。

预测器为 `128→64→64`，Corrector 为 `192→64→768`，均为 Linear/GELU/Linear；Anchor 为无 bias 的 `64→768`。各层参数独立。gain 形状为 `[12,1,128,768]`，零初始化，其余线性层正常初始化。第一层没有分配闲置 predictor。新增可训练参数 **2,653,312**；投影是 buffer，不计入可训练参数。

`tanh` 只限制增益，不保证整个残差范数有界；实现没有额外归一化方向、范数截断或事后尺度重标定。

### 四组的方向、增益与 token 范围

- HI1：文档完整方案，`0.25*tanh(G)*D`，仅修正patch。
- HI0：与HI1相同结构，仅去掉预测辅助损失；预测器仍参与前向并可获得身份梯度，不是冻结预测器。
- HI2：保留有界增益，扩展为CLS＋全部patch。CLS有自身的状态、历史预测残差、上一层修正和零初始化gain，不能用patch修正的均值代替。
- HI3：保留patch-only，只改成 `0.25*G*D`。不移除0.25，不归一化D，不同时修改学习率。

HI2的CLS与patch共享各层的P、Predictor、Anchor、Corrector；独立增加 `[12,1,1,768]` 的CLS gain，共9,216个参数，总新增参数2,662,528。其余三组仍为2,653,312。实现分别计算patch和CLS分支，保持patch网络的初始化和矩阵计算尺寸与HI1相同；CLS零增益不消耗初始化随机数。

四组的预测损失**只监督128个patch**，不加入CLS目标、不改变平均分母。CLS没有直接的预测辅助项，但共享predictor仍会受到patch预测监督影响；CLS gain通过身份损失学习。

HI1与HI3在G=0处，输出修正同为0，对G的导数同为0.25D。非零时的差异来自tanh非线性、边界及梯度衰减。若G一直很小，结果接近是合理现象，不能仅凭“有界”推断它压制了修正。

## 3. 损失和梯度

每个 iteration 检查全部第 2—12 层，按层均值，不轮换，无额外网络前向：

`L_pred = mean_l SmoothL1(pred_delta_l, sg(S_l - sg(S_{l-1})))`

PyTorch `smooth_l1_loss(beta=1.0, reduction='mean')` 先在 batch/patch/channel 上平均，再对 11 层平均。

`L_total = L_CE + L_Triplet + lambda_pred * L_pred`

- HI1/HI2/HI3 的 `lambda_pred=1.0`，从 epoch 1 启用；不用旧 C 方案的 epoch6 warmup，也不动态标定。
- 目标和历史缓存 detach；预测损失直接更新 predictor，不直接推动当前状态/主干迎合预测值。
- 身份损失通过当前状态、创新量、方向器和写入路径更新主干与适配器，包括 predictor。它是联合任务优化下的预测残差，不是纯统计预测器。
- gain 初始为零时，身份梯度首先到 gain；方向器此时身份梯度为零是预期行为。HI1 predictor 可同时从预测损失启动，gain 更新后方向器也获得身份梯度。
- 小型投影、预测、方向器与残差计算使用 FP32，再将实际写入残差转回主流 dtype；主干沿用原 AMP。历史缓存保存实际写入的残差。

参数 `rank=64、alpha=0.25、lambda=1` 是文档示例基础上的首轮预设，不是局部搜索最优值。局部 smoke 仅查执行正确性，不用于选参，不据损失值决定是否放大。

## 5. 日志与可证伪诊断

- `history_epoch.jsonl`：每 epoch 一个合法 JSON，记录实际 iteration、CE、Triplet、raw/weighted prediction、AMP 跳步、patch gain RMS和实际TOKEN_SCOPE/GAIN_MODE。
- 每 epoch 首个 batch 与每 50 iteration 记录逐层诊断，epoch 汇总是这些抽样 batch 的均值，**不是全训练样本统计**。
- 每epoch记录 `gain_distribution`：patch（以及HI2的CLS）的绝对值p50/p95/p99/max、RMS、|G|>1/2比例、有效增益最大绝对值、增益函数平均导数。它们帮助判断tanh是否进入明显非线性区，不能用gain RMS单独判断饱和。
- HI2另有逐层CLS修正RMS与修正/CLS输入RMS比；原逐层修正字段仍只对应patch。
- 逐层字段：状态 channel 方差、创新量 RMS、修正 RMS、修正/输入 RMS 比、预测 RMS、目标 RMS、预测 MSE、复制上一层的 MSE。
- `prediction_gain_ratio_of_means = 1 - mean(prediction_mse)/mean(copy_mse)` 为抽样累计误差比；`prediction_gain` 为逐 batch 比值的均值。分析优先使用前者，分母趋零时联合检查目标 RMS。
- PG>0 仅表示优于复制，不能证明检索有效。低预测损失也可能来自目标变化缩小；需同时看状态方差/目标 RMS。
- 不加入未经验证的“残差必须平滑”或“创新量必须归零”约束。
- BN 只由原训练主前向更新；无开关对照分支、无冻结参考模型、无增强教师前向。

## 6. 与 PDF 参考代码的实现差异

1. 保留现有训练、optimizer、scheduler 和 evaluator，没有使用 PDF 的独立 ReIDInterface 替换整个项目。
2. 原项目约定 post-BN 主结果、pre-BN 补充，覆盖 PDF 的 pre-BN 单一测试示例。
3. 明确监督全部第2—12层；默认从第一epoch计算固定权重预测损失。
4. 不分配首层永远不会调用的 predictor；模块参数按原规则使用新增参数学习率。
5. 固定投影和推理相关规格随 checkpoint 保存；禁止把 baseline/C0 权重误当 HI checkpoint 加载，alpha、增益形式、token范围不匹配也会报错；原HI0/HI1 checkpoint签名保持兼容，HI2/HI3具有不同签名。
6. 初始增益为零的主干函数保持检查、RNG 隔离和 FP32 辅助计算用于保证数值可比，不改变核心算法。
