## 2. 先单独执行192图AMP预检

ACP申请1张A800-80GB，前台执行：

```bash
bash /mnt/cache/wanghanzhi/XK/Trajectory_history_p2/server/history_p2/sensecore/preflight_P2.sh
```

脚本固定单卡`CUDA_VISIBLE_DEVICES=0`、`WORLD_SIZE=1`。实际预检工具命令为：

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 /mnt/cache/wanghanzhi/envs/llmpar/bin/python3 -u /mnt/cache/wanghanzhi/XK/Trajectory_history_p2/tools/smoke_history_p2.py --pretrained /mnt/cache/wanghanzhi/Datasets/ViT-B-16.pt --data-root /mnt/cache/wanghanzhi/Datasets --batch-size 64 --num-instance 4 --steps 16 --output /mnt/cache/wanghanzhi/XK/Trajectory_runs/history_round2_1016/P2_preflight_seed1234
```

该预检只重复一个真实192图batch，进行16次优化尝试，使用原MAX_EPOCHS=60、真实sampler的iteration尺度及100步warmup，结束后保存短循环权重并停止。`transformer_1.pth`只是这个短循环的输出，不是完整1epoch结果，也不作为正式实验续训起点。

成功应出现`P2_PREFLIGHT_OK`，报告实际图数192、K4、跳步和实际更新、严格重载及梯度检查；至少2次真实更新才通过。还应验证gain启动后融合、3×3卷积、5×5卷积、升维网络均收到任务梯度，空间更新不再全零，Predictor不收任务梯度。

原llmpar有已知torch/torchvision不配套提示，本次没有自动修改环境；以本次192图真实预检结果判断能否继续。CPU或本地小batch通过不替代这个服务器预检。

## 3. 再独立启动正式60epoch

预检通过后，另建1张A800的ACP任务，前台执行：

```bash
bash /mnt/cache/wanghanzhi/XK/Trajectory_history_p2/server/history_p2/sensecore/run_P2.sh
```

脚本不会自动调用预检，也不加载预检权重。它从CLIP预训练和指定随机初始化完整训练60epoch；随后重新加载同一`transformer_60.pth`，执行post-BN主测试和pre-BN补充测试。

等价完整训练入口如下：

```bash
cd /mnt/cache/wanghanzhi/XK/Trajectory_history_p2
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 /mnt/cache/wanghanzhi/envs/llmpar/bin/python3 -u /mnt/cache/wanghanzhi/XK/Trajectory_history_p2/train.py --config_file /mnt/cache/wanghanzhi/XK/Trajectory_history_p2/configs/history_P2.yml MODEL.PRETRAIN_PATH /mnt/cache/wanghanzhi/Datasets/ViT-B-16.pt DATASETS.ROOT_DIR /mnt/cache/wanghanzhi/Datasets HISTORY.STOP_AFTER_EPOCH 0 OUTPUT_DIR /mnt/cache/wanghanzhi/XK/Trajectory_runs/history_round2_1016/P2_seed1234
```

通常用`run_P2.sh`，因为它还保存代码版本、配置并运行两种最终读出。不要对相同目录同时运行脚本与等价入口。输出已存在时脚本退出；重试须显式另设独立retry目录，保留旧产物。

## 4. 核对正式参数

| 项目 | P2设置 |
| --- | --- |
| 方法/旧增强 | HISTORY.ENABLED=True、METHOD=p2；旧C0、VPR、文本关闭 |
| rank/alpha/gain/token | 64 / 0.25 / linear / patch-only |
| 层号 | block1只采集状态；写入/预测block2–12 |
| 低维融合 | `E + GELU(Linear192→64([S,E,Q]))` |
| 空间网格 | 高16、宽8；按原patch顺序恢复 |
| 空间卷积 | 并行3×3/5×5、groups64、无bias、padding1/2、零核、各1/2 |
| 升维/归一化 | GELU→Linear64→768→非仿射LN(eps1e-5)→gain |
| 预测器 | 128→64→64；末层零初始化；历史/目标detach，任务参照detach |
| loss | 原CE＋SoftMargin Triplet＋1×11层平均SmoothL1 |
| LR | 主干5e-6；头/gain3.5e-4；Predictor及全部方向网络1e-4 |
| WD | 主干/头/Predictor为1e-4；gain和全部方向网络为0 |
| clip | AMP unscale后任务组整体1、预测组整体1，不做共同全模型clip |
| 图像/模态/batch | 256×128；RGB/IR/Thermal；逻辑64、K4、实际192图 |
| 主干/日程 | CLIP ViT-B/16、DropPath0.1；60epoch cosine、warmup100iteration、起始0.01、最低0.002 |
| seed | 训练1234、模块初始化1235，与P1匹配的P初值 |
| 评估 | 每10epoch；固定epoch60 post-BN主读出、同权重pre-BN补充 |

所有原数据增强、CLIP mean/std、身份标签、BNNeck及检索相机过滤保持，不开reranking，不增加训练组或参数扫描。P2不包含P1 Anchor/Corrector，也没有第二套密集gain。
