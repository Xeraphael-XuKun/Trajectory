## 2. 速度、历史与层边界

公式层号1–12，源码layer0–11。H_l为本层修正前输入，X_l=H_l+R_l，原block输出H_(l+1)=B_l(X_l)。

**真实block速度为 `V_l = H_(l+1) - X_l`。** 它不包含适配器直接加到block输入的那一步；不能用`H_(l+1)-H_l`替代。实现复用原block循环，在全部修正写入后保存block_input，原block执行完毕后计算output-block_input；不detach这一真实速度。

P3没有固定投影P、低维状态S、Anchor、Corrector、空间卷积或上一动作投影Q。

| 当前block | 当前观察量 | 预测历史 | 写入 |
| --- | --- | --- | --- |
| 1 | 无Z1，不人为构造零速度观察量 | 无，不缓存虚构状态 | R1=0 |
| 2 | Z2=LN(V1)，全部129token | 不调用Predictor；保存Z2.patch的detach副本 | 全token速度分支 |
| 3 | Z3=LN(V2) | Z2.patch；旧增量为零 | 全token速度＋patch创新 |
| 4–12 | Z_l=LN(V_(l-1)) | 最近两条真实patch速度观察量及其差 | 全token速度＋patch创新 |

新增LN为沿768通道、非仿射、epsilon1e-5。状态、预测、创新归一化及分支计算采用FP32，最终残差转回主干token dtype；原block保留AMP、attention、MLP、dropout和DropPath。

历史只在同一次图像前向内存在，保存真实观察量Z的detach副本，保留最近两条；不保存预测值作为未来观察量，不跨图像/batch，不读取未来层。主C0速度路径本身保留梯度。

## 3. 预测与双支路公式

从block3开始：

```text
old_delta = 0                                      (block 3)
old_delta = sg(Z_(l-1).patch - Z_(l-2).patch)        (block 4–12)
pred_delta = Predictor_l([sg(Z_(l-1).patch); old_delta])
Z_hat_l = sg(Z_(l-1).patch) + pred_delta
E_l = Z_l.patch - sg(Z_hat_l)
```

Predictor逐层独立，为`1536→32→768`，标准GELU、两层有bias，共10套。输入/输出是全维768速度表示，32只是内部瓶颈。不向Predictor输入当前Z、当前目标、E或上一动作；不对预测状态额外做LN。

```text
R_l.velocity = G_l.velocity * LN(V_(l-1))           (block 2–12，CLS＋patch)
R_l.innovation = 0.25 * G_l.innovation * LN(E_l)     (block 3–12，仅patch)
R_l = R_l.velocity + [0; R_l.innovation]
```

block2只有速度分支。两条方向分别归一化、分别乘gain后相加，不对总残差再做LN，不给速度分支乘0.25，不先合成方向再共享gain。创新量是分别归一化速度之间的预测残差，不能替换成原始速度差的LN。

CLS只有C0速度写入，没有CLS创新、Predictor或预测辅助loss。外部`MODEL.TOKEN_TRAJECTORY=False`，P3内部只保留一份速度执行器。

## 4. 初始化、梯度与参数量

新模块在视觉预训练加载后用fork_rng隔离CPU随机流，INIT_SEED=1235；不改变原头初始化和后续随机序列。两套gain全零，Predictor末层权重/bias全零，其余线性层采用按输入维度的均匀初始化。初始预测增量为0，预测参照为上一真实归一化速度；没有随机高维方向网络。

| 参数族 | 形状/层 | 参数量 | 直接梯度 |
| --- | --- | ---: | --- |
| velocity_gain | `[11,1,129,768]`，block2–12 | 1,089,792 | 身份任务 |
| innovation_gain | `[10,1,128,768]`，block3–12 | 983,040 | 身份任务 |
| predictors | 10套1536→32→768 | 745,280 | 预测loss |
| 总新增可训练参数 | 已包含内置C0 | **2,818,112** | 无固定投影buffer |

当前Z在速度和创新路径保留任务梯度；真实V到实际block输入、输出及更早主干的梯度不主动截断。历史副本、预测目标detach；预测结果进入E前detach，所以身份loss不直接训练Predictor，预测loss不直接训练主干或两套gain。数值前向和未来训练轨迹仍相互影响，不能称为两个完全独立模型。

## 5. 损失、优化和统一设置

`L = CE + Triplet + 1*L_pred`。CE不做label smoothing；原Triplet为batch-hard欧氏距离/SoftMarginLoss，不增加特征归一化或0.3 hinge margin。

L_pred用beta1的SmoothL1，目标`sg(Z_l.patch-Z_(l-1).patch)`。每层对实际图像batch×128patch×768通道求mean，再平均block3–12的10层；不计首两层/CLS，不使用P1/P2的11层或64维分母。从训练开始启用，无额外预测warmup。

| 参数族 | 峰值LR | coupled WD |
| --- | ---: | ---: |
| CLIP预训练主干 | 5e-6 | 1e-4 |
| BNNeck、分类头 | 3.5e-4 | 1e-4 |
| velocity_gain | 3.5e-4 | 1e-4 |
| innovation_gain | 3.5e-4 | 0 |
| Predictor含bias | 1e-4 | 1e-4 |

使用原Adam，不覆盖betas/eps，不改AdamW。AMP backward后unscale，再将任务参数整体和Predictor参数整体分别按L2总范数1裁剪，不先做全模型共同clip。两组不重叠且覆盖全部可训练参数；WD由Adam内部加入。

正式配置：共享CLIP ViT-B/16、256×128、12block/768维、DropPath0.1，RGB/IR/Thermal、原PKM/K4、逻辑batch64/实际192图，原增强与CLIP norm；训练seed1234，模块seed1235。60epoch cosine、100iteration warmup、起始0.01、最低0.002；每10epoch评估，最终固定epoch60 post-BN为主、同权重pre-BN补充。不开reranking，不增加教师、文本、模态专属参数、额外完整主干前向或残差预算。

P3的`HISTORY.ALPHA`只控制创新系数，TOKEN_SCOPE=all描述速度分支；创新范围单独固定patch。resolved配置中保留的RANK、WRITE_WEIGHT_DECAY属于旧History字段，不控制P3结构或衰减；实际P3使用PREDICTOR_HIDDEN_DIM=32和上述三族显式分组。

## 6. 已完成验证与实际证据

CPU使用真实CLIP权重和WHU-MARS小批次，已得到`P3_CHECK_OK`：

- 手算首层/第二层/第三层边界、非零预测与两类gain、CLS仅速度写入、历史截断和两类直接梯度均符合定义。
- 对比30eaccc历史backbone与wrapper：baseline/C0参数、固定随机前向及优化器规则一致；P3两套gain为零时，基础参数、输出和RNG与baseline一致。
- 非零velocity_gain、零innovation_gain下，CPU/FP32完整训练前向逐元素复现原C0；这不等于任意dtype或训练结果都有性能下界。
- 在完整P3模型同时启用非零两套gain，用block pre/post hook核对每层速度恰为output-已修正input，并确认它不同于含上一动作的相邻状态差。
- loss准确平均10个768维预测层；两次CPU实际Adam更新确认两套gain启动、Predictor仅接受预测梯度、主干任务梯度可达、LR/WD及裁剪集合正确。
- 完整state_dict严格磁盘重载、原load_param alpha规格拒错、pre/post读出和前向间状态清空通过。

复核中曾发现公共构建处误把旧History的rank替换为P3隐藏维度，已恢复为原RANK，并单独得到`P3_LEGACY_CHECK_OK`：旧HI1 rank64的初值、非零gain前向、预测loss及优化器与30eaccc一致。该修正不改变已验证的P3路径。

本地AMP预检使用RTX3050 Laptop、Python3.10.20、torch1.13.1+cu117、torchvision0.14.1+cu117、timm1.0.19，复用现有work/check-deps，未安装依赖。12图/2身份的同一真实batch重复16次尝试，7次初期AMP跳步、9次实际更新，得到`P3_PREFLIGHT_OK`；训练峰值显存约2.755GiB。K2/逻辑batch4只是本地显存下的检查，仍保留60epoch日程与真实sampler的iteration尺度，不是正式K4/192图实验。
