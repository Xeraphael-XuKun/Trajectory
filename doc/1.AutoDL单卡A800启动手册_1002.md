## 2. 路径约定与环境边界

llmpar 路径由你本轮确认；数据、权重、whu_mars 路径按你要求沿用 WHU-Baseline 的《7.AutoDL单卡A800实验手册_0929.md》，已核对该手册与旧启动脚本。代码使用新的独立 Trajectory 目录，不覆盖原 WHU-Baseline。下表已写入本轮启动脚本；本次未登录实例实测文件是否存在。如路径另有变化，按第5节覆盖，不必修改 YAML 或 Python。

| 项目 | 默认路径 |
|---|---|
| 代码 | /root/autodl-tmp/XK/Trajectory |
| llmpar Python | /root/autodl-tmp/envs/llmpar/bin/python3 |
| whu_mars Python | /root/autodl-tmp/envs/whu_mars/bin/python3 |
| CLIP 权重 | /root/autodl-tmp/ViT-B-16.pt |
| 数据集实际位置 | /root/autodl-tmp/WHU-MARS |
| DATASETS.ROOT_DIR | /root/autodl-tmp |
| 输出父目录 | /root/autodl-tmp/XK/Trajectory_runs/autodl/matrix_minimal_1001 |

数据结构应为 `/root/autodl-tmp/WHU-MARS/{train,query,test}/{RGB,IR,Thermal}/...`。本项目 `datasets/whu_mars.py` 会拼接 `root/WHU-MARS`，因此 **ROOT_DIR 传父目录 /root/autodl-tmp，不传 /root/autodl-tmp/WHU-MARS**。不修改数据加载器来适配路径。

使用已准备好的 llmpar / whu_mars 两套环境，不能用 AutoDL 默认 Python 冒充任意一组，也不能因为环境名字相同就认定依赖一致。若本实例只有 whu_mars，可先运行四个 W 组；L 组等对应环境准备好后再运行，不能自动切换到 W 或默认 Python。不要直接 `pip install -r requirements.txt`，以免改变环境对照。

若环境未按商汤的实际 Python、torch、torchvision、timm、CUDA/cuDNN 版本迁移，应将结果标注为“AutoDL 对应实际环境的探索结果”，暂不并入原环境严格对照。相同 A800 型号也不保证两平台逐步数值完全相同。原日志的 Runtime 行保留，可记录实际版本、GPU及cuDNN开关。

## 5. 路径不同时的最小覆盖

脚本支持以下**仅路径**参数；每项有明确默认值，无需改训练代码或另复制 YAML：

| shell 参数 | 作用 |
|---|---|
| TRAJECTORY_CODE_DIR | 代码目录 |
| LLMPAR_PYTHON | 仅供 L 组的 Python 绝对路径 |
| WHU_MARS_PYTHON | 仅供 W 组的 Python 绝对路径 |
| TRAJECTORY_DATA_ROOT | 数据集父目录 |
| TRAJECTORY_CLIP_WEIGHT | ViT-B-16.pt 的绝对路径 |
| TRAJECTORY_RUN_DIR | 当前这一次实验独立的输出目录 |

例如按上述默认路径重跑 `W_S_T`，但使用独立 retry1 目录：

```bash
TRAJECTORY_CODE_DIR=/root/autodl-tmp/XK/Trajectory \
WHU_MARS_PYTHON=/root/autodl-tmp/envs/whu_mars/bin/python3 \
TRAJECTORY_DATA_ROOT=/root/autodl-tmp \
TRAJECTORY_CLIP_WEIGHT=/root/autodl-tmp/ViT-B-16.pt \
TRAJECTORY_RUN_DIR=/root/autodl-tmp/XK/Trajectory_runs/autodl/matrix_minimal_1001/W_S_T_seed1234_retry1 \
bash /root/autodl-tmp/XK/Trajectory/server/autodl/run_W_S_T.sh
```

实际路径不同时，把对应绝对路径改为真实值；最后一行脚本自身路径也要匹配代码所在目录。不要跨组共用一个 `TRAJECTORY_RUN_DIR`，不要把 L 组指向 W 的解释器。

同组重复训练须使用新的 retry 输出目录，保留旧日志和权重。脚本不自动恢复、不自动重试、不拒绝已有目录；原训练入口重跑会从CLIP初始权重开始，并可能覆盖同目录的epoch60权重。
