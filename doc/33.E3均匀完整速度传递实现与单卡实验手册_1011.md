## 2. 精确实现

block1 无修正。对 block2—12，上一 block 的完整速度定义为原始输出减实际输入，包含本次 attention、MLP 与 DropPath 的实际更新：

$$
V_{l-1}=Y_{l-1}-X_{l-1},\qquad
\bar V_{l-1}=\frac1T\sum_{s=1}^{T}V_{l-1,s},\qquad
R_l=G_l\odot\operatorname{LN}(0.5V_{l-1}+0.5\bar V_{l-1}).
$$

$$
X_l=H_{l-1}+R_l,\quad Y_l=B_l(X_l),\quad V_l=Y_l-X_l,\quad H_l=Y_l.
$$

均值只沿每张图的 token 维求取，包含 CLS；不跨 batch、不跨模态聚合。均值依赖当前图像，属于动态速度观测，不是静态 bias。修正持续留在状态中，最后按原路径仅做一次最终 LN 并读取 CLS。

局部关闭 autocast 后：速度转 FP32 → `mean(dim=1, keepdim=True)` → 固定0.5混合 → 通道 functional LN（无 affine、epsilon=1e-5）→ 转回速度实际 dtype → 乘同 dtype gain。完整速度和均值分支均保留梯度；不增加参数化混合系数。

无需构造稠密均匀矩阵或读取 attention 副本；本分支原 `Attention.forward` 与 `Block.forward` 完整保留。每个 block 仍只调用一次，P/V 的历史不存入 self。新循环与原历史循环分开。

唯一新增可训练参数为零初始化 gain `[11,1,129,768]`，共 **1,089,792** 个。签名 buffer 为 `[703,1,12,129,768,0,0.5,0,0,1,1e-5]`，不进入优化器。gain 有符号、无界，无 sigmoid/tanh、额外 bias 或低秩网络。
