## 2. 精确执行与层边界

公式层号从1开始，源码`layer`从0开始；`H_l`始终是当前block修正前输入。

1. 先计算修正前patch状态：`S_l = LN(H_l.patch) P`。LN沿768通道、非仿射、epsilon为`1e-5`；`P`是共享的768×64固定正交buffer。
2. block 1只采集`S_1.detach()`并执行原block。无预测器调用、方向计算、写入或预测loss，也不为该层分配闲置网络/gain；上一动作投影为零。
3. block 2–12：Predictor输入为`[sg(S_(l-1)); sg(S_(l-1)-S_(l-2))]`；block 2缺旧增量时补零。逐层Predictor为`128→64→64`，标准GELU，两层带bias。
4. `S_hat_l = sg(S_(l-1)) + Predictor_l(...)`；`E_l = S_l - sg(S_hat_l)`。预测器不读取当前状态，身份任务不直接训练预测器。
5. `Q_(l-1) = sg(R_(l-1).patch) P`，取真正写回主干、完成dtype转换后的残差，保持FP32投影；不改用上一方向，也不对Q做LN。
6. `D_l = Anchor_l(E_l) + Corrector_l([S_l; E_l; Q_(l-1)])`。Anchor是无bias的`64→768`；Corrector是带bias的`192→64→768`与GELU。
7. `R_l.patch = 0.25 G_l ⊙ LN(D_l)`，`R_l.CLS = 0`，随后执行原`Block_l(H_l + R_l)`。顺序固定为“两条方向相加→LN→线性gain”，不使用tanh，不给残差再加LN、预算或裁剪。
8. 缓存本层修正前`S_l.detach()`及实际动作投影，状态只保留最近两层；每次图像前向重新建立，无跨batch或跨图像缓存。

新增小分支在禁用autocast的FP32计算，写入时转换至主干token dtype；原block内部和DropPath保持。推理仍执行投影、历史预测、方向及写入，不构造预测目标或loss。

## 3. 初始化、梯度与参数量

新模块在CLIP加载后用`fork_rng(devices=[])`及初始化seed1235构建，恢复原CPU RNG，不改变原头初始化或后续随机序列。采样固定投影是该隔离随机流的第一个随机操作；未来P2须以相同seed、相同首个QR操作复用相同P。

线性层采用PyTorch `nn.Linear`的均匀初始化，即权重/bias范围`±1/sqrt(in_features)`。Predictor最后一层权重和bias全零；gain全零；Anchor与Corrector保持非零初始化，不增加dropout或内部LN。

| 参数族 | 元素数 | 直接梯度来源 |
| --- | ---: | --- |
| patch gain，`[11,1,128,768]` | 1,081,344 | 身份任务 |
| 11个Predictor | 136,576 | 预测loss |
| 11个Anchor | 540,672 | 身份任务 |
| 11个Corrector | 684,992 | 身份任务 |
| 总新增可训练参数 | **2,443,584** | 不含固定P的49,152个元素 |

零gain时方向网络任务梯度为零，gain可以启动；gain更新后方向网络获得任务梯度。当前S可接收任务梯度；历史、上一动作和进入任务路径的预测值停止梯度。预测loss的目标与输入历史均detach，只更新Predictor。

## 4. 损失、优化器及训练参数

`L = CE + Triplet + L_pred`。CE不做label smoothing；Triplet沿用batch-hard欧氏距离、SoftMarginLoss，不额外归一化输入、不启用0.3 hinge margin。

`L_pred`是block 2–12的增量SmoothL1(beta=1)：每层对实际图像batch×128patch×64通道求mean，再对11层求mean。权重1，从训练开始启用，不添加预测或写入warmup。

| 参数族 | 峰值学习率 | coupled weight decay |
| --- | ---: | ---: |
| CLIP预训练主干 | 5e-6 | 1e-4 |
| BNNeck、分类器 | 3.5e-4 | 1e-4 |
| P1 gain | 3.5e-4 | 0 |
| Anchor、Corrector（含bias） | 1e-4 | 0 |
| Predictor（含bias） | 1e-4 | 1e-4 |

使用原Adam；源码未覆盖其betas/eps。bias学习率系数1。先AMP backward、`scaler.unscale_(optimizer)`，再将任务参数整体和预测参数整体分别以总L2范数1裁剪，最后由Adam加入coupled decay并更新；不是逐层clip，不再先做全模型clip。两个集合互不重叠且覆盖全部可训练参数。

固定设置：共享CLIP ViT-B/16、256×128、16×8 patch、768维、12block；RGB/IR/Thermal；PKM/K4；逻辑batch64、实际192图；原CLIP norm与增强；DropPath0.1；60epoch cosine、100 iteration warmup、起始因子0.01、最低因子0.002；训练seed1234。每10epoch评估，epoch60保存后独立测试post/pre；不开reranking。

`HISTORY.METHOD`默认`legacy`，原HI/HD/HF继续执行原模块、原优化器规则和全模型clip。只有`METHOD: p1`且History开启时执行P1网络学习率和分组裁剪。P1构建拒绝与旧C0/VPR/文本等增强同时启用。

## 6. 结论边界

当前只证明P1在上述检查范围内接入正确、能够更新，没有正式检索成绩。P1同时改变方向LN、首层、初始化、梯度、学习率和clip，不是第一轮HF的单因素消融。方向LN不约束最终残差RMS，零gain也不保证长期优于baseline。

服务器还必须完成原llmpar环境的单A800/192图AMP预检，再由用户独立启动60epoch。所有结果按固定epoch60 post-BN报告，与历史C0比较时保留历史对照、单seed的边界；不挑读出或checkpoint。启动命令、输出及材料回收见配套第43号手册。
