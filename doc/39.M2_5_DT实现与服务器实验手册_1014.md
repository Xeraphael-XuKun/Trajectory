## 2. 实际计算路径

`train.py -> 原loader/model/CE+Triplet -> processor.do_train -> utils.direct_text.text_ce`。

$$
z=\operatorname{normalize}(g_{preBN}P_0),\quad
L=L_{CE}+L_{Triplet}+0.5\,CE(zT_0^\top/0.07,y).
$$

使用全部500身份，不只当前batch的16个。原视觉前向只有一次；原BNNeck/分类器仍只用于主CE。新增项回传视觉backbone与C0 gain，对BNNeck/classifier没有直接梯度；主任务仍正常更新它们。P0在创建optimizer之前冻结，T0为训练循环一次加载的只读tensor，不注册为模型参数或持久化buffer；文本塔、教师、LoRA不会构造。

原C0、Triplet/sampler/metrics文件未修改。开关默认关闭，不读文本文件、不构造新模型模块。原`TEXT_ALIGN/VPR/MOD_DELTA`均关闭。此父版本没有`C0_AUX/TERMINAL_REPAIR`配置块及对应接入，不为禁用它们而重新添加旧模块。

实际配置与M5差异仅方法启用/资源路径、输出目录和不使用的教师输出字段；本地检查的CLIP/数据路径覆盖另记录。保留seed1234、60epoch、逻辑batch192、Adam主干5e-6/新参数3.5e-4、WD1e-4、原AMP及clip1.0。warmup100名义调度步，保持`(epoch-1)*len(loader)+n_iter`时钟；不是5epoch warmup，也不按成功更新重新计时。

## 5. 服务器分开执行三步

源码放至建议位置后，先检查文件资源是否已按第3节准备。以下每条为独立前台单卡命令。

### 5.1 预检：完整192图合成batch

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-5-direct-text/Trajectory/server/m2_dt/preflight.sh
```

生成`preflight/implementation_check.json`，预期状态`PASSED_SERVER_192_SYNTHETIC_PREFLIGHT`。验证原始视觉前后向、500类损失、AMP一次优化及完整/部署重载；合成输入不代表检索性能。此命令**不会启动60epoch训练**。

### 5.2 正式训练：原train.py，完整60epoch

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-5-direct-text/Trajectory/server/m2_dt/run_train.sh
```

脚本前台执行固定解释器与新配置，追加保存`train.log`。每50个batch记录主CE/Triplet、raw/weighted文本CE、文本acc/概率/熵、unscale后裁剪前gain/global梯度及实际iteration/update/AMP跳步；周期评测仍每10epoch。日志点均值不能假作全epoch均值，文本acc不能假作未知身份检索。

重复正式训练必须用新输出目录；已有初始化记录时会停止以保护原实验。不从C0/M5 epoch60学生或教师开始。明确断点恢复时可传入**本组full** checkpoint：

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-5-direct-text/Trajectory/server/m2_dt/run_train.sh M2_DIRECT_TEXT.RESUME /mnt/cache/wanghanzhi/XK/Trajectory_runs/m2_05_direct_text_c0_seed1234/transformer_60.pth
```

通常本组只在最终epoch60保存，所以这条是恢复接口示例，不表示已具有可用中期断点；不要用部署文件恢复训练。full保存optimizer/scheduler/scaler/RNG及预算。若恢复的是已完成epoch60，只会结束循环，不新增60epoch。

### 5.3 独立评测：同一epoch60权重post主/pre辅

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-5-direct-text/Trajectory/server/m2_dt/eval_epoch60.sh
```

两次严格加载`transformer_60_student.pth`全部模型state（包括BN/classifier），使用原`do_inference`与sysu同相机全部过滤、L2特征、无rerank；6405 query/93609 gallery、九模态及平台分组。模型构造关闭训练文本开关，不读取T0，不运行教师。只因沿用视觉构造仍需原CLIP文件，不要求部署的文本外部依赖。
