## 1. 本次究竟组合什么

以首轮HI3替代原始方案五M2-e中的C0学生；复用原M2-e已经训练好的共享P-ID文本表与条件Q/V LoRA教师。教师仍是无C0、无History的原始冻结视觉主干＋条件LoRA。学生仍从原CLIP、零History gain与原BNNeck/分类器初始化开始，重新训练60epoch。

这里“完整M2-e”指保留原方案五的共享身份文本、条件教师、同增强在线教师输出与KD计算。**不是后续直接文本监督DT，不是R2/FlatTail/OneSided/NoWD，也不是给教师增加HI3。** 缓存、prompt和教师阶段已完成并复用，无需重跑；它们的历史训练成本仍属于完整方法预算。

HI3的精确定义来自原独立History项目，不采用后来HF修改：

| HI3固定项 | 本组 |
| --- | --- |
| 层/范围 | 12个block前，仅128个patch，CLS不直接写入 |
| 坐标 | 768×64固定正交投影，各层共享 |
| 历史 | 同一图像forward最近两条修正前状态及先前实际修正；缓存detach |
| 创新量 | 当前LN投影状态减去历史预测状态 |
| 方向 | Anchor(E)＋Corrector([S,E,sg(r_previous)P])，不额外归一化D |
| 写入 | `r=0.25*G*D`，G零初始化、无tanh；不是`G*D`或HF的α=1 |
| 预测 | 第2—12层全部SmoothL1(beta=1)，按元素再按11层平均 |
| 预测权重 | λ=1，从epoch1启用，无epoch6 warmup |
| 初始化种子 | INIT_SEED=1235，隔离RNG；train seed1234 |
| 学习率/衰减 | 新参数3.5e-4、WD=1e-4，保留bias规则；**不取消写入WD** |

## 2. 为什么现在值得测试，以及不能预设什么

历史HI3的post mAP为首轮最高，但不能称其所有指标均最好；相对C0，mAP只高0.05pp，三个Rank略低。此前检查还发现其终态修正几乎归零。因此，本次是检验“原M2-e监督能否让HI3得到额外收益”，并不是已经证明两个有效机制必然互补。

仍然保留原HI3的WD，是为了回答用户提出的**首轮原版HI3＋原始M2-e**，避免同时换成HF免衰减而偏离问题。如果本组仍出现方向收缩，不能把新组合当成活跃创新量机制的成功；如果总体成绩提高，也要结合修正与参数诊断区分“训练路径影响”和“测试时History贡献”。本组不预先再加WD、α或KD权重搜索。

## 3. 实际损失、特征及梯度

令学生pre-BN特征为g_s，原条件教师pre-BN为g_t，冻结原CLIP投影P0为768×512，共享身份文本T为500×512且行归一化：

$$
\ell_s=\operatorname{normalize}(g_sP_0)T^\top/0.07,\quad
\ell_t=\operatorname{normalize}(g_tP_0)T^\top/0.07.
$$

$$
L_{KD}=2^2\,\operatorname{mean}_{images}
KL\left(\operatorname{softmax}(\operatorname{sg}(\ell_t)/2)
\;\|\;\operatorname{softmax}(\ell_s/2)\right).
$$

$$
L=L_{CE}+L_{Triplet}+1.0L_{pred}+0.5L_{KD}.
$$

KD内部先用基础文本温度0.07，再用Td=2并乘Td²。保持原teacher→student KL方向、全部500身份候选与按图平均，不改成反向KL、hard CE或当前batch身份子集。

- 原CE使用BNNeck/身份分类器，Triplet使用pre-BN，均保持原实现。真实Triplet为无margin的soft-margin batch-hard；配置MARGIN=0.3在这条路径不生效。
- 原M2-e教师处理**与学生完全相同的已增强图像张量**，按RGB/IR/Thermal和零基cam5/6构造条件。教师eval、全部冻结；不使用离线无增强教师输出替代。
- KD直接经过学生pre-BN主干与HI3 gain，不直接经过学生BNNeck/classifier；P0、T、教师均冻结。
- 预测loss只直接更新Predictor；目标及历史detach，当前S身份梯度保留。gain零时方向网络初始身份梯度为零是原结构性质，不当成未接入。
- CE/Triplet/pred/KD共用一次学生主前向、一次正式backward/unscale/全局clip1/Adam step；教师另一次no_grad前向。诊断不增加主干forward。
- 投影、归一化、相似度、KL和History小模块采用原FP32路径，主干沿原AMP。
- 推理仅保留HI3视觉学生；不需要教师、文本或条件标签进入视觉分支。
