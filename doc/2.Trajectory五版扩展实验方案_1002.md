## 2. 保留的核心与代码边界

对第 l 个 block，先注入上一段历史生成的校正，再记录真实 block 输入：

```text
block_input = x + correction
x = block(block_input)
v_l = x - block_input
a_l = v_l - v_(l-1)
```

T0 的下一层校正为 `G * LN(v_l + a_l)`。LN 为当前沿通道的无仿射 LayerNorm，先 FP32 计算再转回激活 dtype。第0个 block 无校正，第1个 block 只有速度，后续10个 block 可使用加速度。CLS 包含在内。gain 零初始化、没有残差限幅、没有切空间投影。11×129×768=1,089,792个参数。

- `model/backbones/token_trajectory.py` 保持原文件不变；旧配置默认 `TOKEN_TRAJECTORY_VARIANT=dense`。
- 五个候选放在 `model/backbones/token_trajectory_variants.py`，经 `vit_pytorch.py` 最小分支接入。
- T3 的历史为本次 forward 内局部变量，不持久化到模型、不跨样本/batch保存。
- T4/T5 在主干统一初始化之后构造，避免零输出层被覆盖；通过 CPU RNG fork 隔离新增随机初始化。原模块构造顺序、分类头初始化和训练随机流不因新增初始化而被推进。
- 新参数仍位于 `base.token_trajectory.*`，由原优化器已有规则获得 BASE_LR×PE_DELTA_LR_MULT；无需修改优化器。
- 保留旧配置和旧环境矩阵作为历史资料，本轮只运行下述新配置。

优先 T1/T2/T4；有第四个实验名额时加入 T3。T5 放在第二批；C0 用于检验加速度是否确实贡献收益。T0 新配置用于需要配对复核时重新训练，不要求为了新文件名重复已经完成的相同实验。

### T1：自适应加速度

```text
c = cosine(v, old_v)
r = tanh(log((RMS(v)+1e-6)/(RMS(old_v)+1e-6)))
beta = 2 * sigmoid(b + w*c + u*r)
correction = G * LN(v + beta*(v-old_v))
```

每个有加速度的位置学习两组 `(b,w,u)`，分别用于 CLS 与 patch。patch 共享预测器，但每个样本、每个 token 的 c/r 不同；共10×2×3=60个参数。预测参数全零初始化，beta 初始为1。c/r 使用 detached FP32 统计；v和a的方向主路径保留梯度。第一处注入仍为速度。该版本以固定初始 beta=1 的方案定义，ACCEL_MIX 不是其动态 beta 的额外倍率。

假设：不同轨迹需要不同外推强度。风险：beta 退化为几乎固定的层级系数。后续分析可按 CLS/patch 和层记录 beta 分布；不能把余弦一致性直接解释为身份可靠性。

### T2：速度与加速度双分支

```text
correction = Gv * LN(v) + Ga * LN(v-old_v)
```

Gv 为11组，Ga为10组，不分配无历史时用不到的加速度参数。两组均零初始化。第一处仅速度；其余位置同时执行两分支。保持原 LayerNorm 类型，不改变输入 CLIP normalization；ACCEL_MIX=1。

假设：速度与加速度需要独立的 token/channel 处理，提前相加可能掩盖某个分量。风险：额外容量和微弱加速度归一化放大噪声；若有效，不能只凭这组实验将增益完全归因于解耦。

### T3：平滑历史外推

```text
m_0 = v_0
m_l = 0.25*m_(l-1) + 0.75*v_l
correction_next = G * LN(2*m_l - m_(l-1))
```

第一处校正使用 m_0；后续继续原外推形式。历史不 detach，无新增参数。rho=0.25 时，方向等于 `1.5*v_l - 0.5*m_(l-1)`。

不能把 rho=0.5 当作普通的平滑候选：此时 `2*m_l-m_(l-1)=v_l`，恰好退化成 velocity-only。假设是减少短时噪声；风险是延迟真实语义转向。原 DropPath=0.1 保持不变，不另加正则化对照。

### T4：样本相关 token 强度

```text
q = concat(LN(v), LN(v-old_v))
s = 0.5 + sigmoid(Linear16to1(GELU(Linear1536to16(q))))
correction = s * G * LN(v + (v-old_v))
```

各层独立预测器、token共享，hidden=16。第一处无加速度时，q的后半段填零。输出层权重/bias全零，初始s=1；范围(0.5,1.5)。原gain仍是无界参数，不能称整个校正被限制到此范围。

假设：相同位置在不同图片中需要不同校正幅度。风险：门控也可能增强稳定背景；没有前景/姿态监督，不能称其已学到人体定位。T1调方向，T4调幅度，适合在两者独立有效后组合。

### T5：轨迹通道混合

```text
z = LN(v + (v-old_v))
correction = G*z + Wup(GELU(Wdown(z)))
```

rank=16，down/up无bias，各层独立、token共享；down随机初始化、up全零初始化。原dense路径保留，不冻结主干。输入来自轨迹而不是另建普通当前特征分支。

假设：逐元素gain的跨通道表达不足。风险：容量增加使机制归因更困难。瓶颈结构与既有Adapter思路有关，不能仅凭结构宣称新颖性；参见 [AdaptFormer](https://proceedings.neurips.cc/paper_files/paper/2022/hash/69e2f49ab0837b71b0e0cb7c555990f8-Abstract-Conference.html)。

## 4. 固定训练设置

| 项目 | 设置 |
|---|---|
| 环境 | 已有 llmpar，不安装/升级依赖 |
| cuDNN | benchmark=True，deterministic=True |
| 数据 | WHU-MARS-1000，RGB/IR/Thermal，原split与评测协议 |
| 主干、输入 | CLIP ViT-B/16，256×128，stride16 |
| normalization | mean=[0.48145466,0.4578275,0.40821073]；std=[0.26862954,0.26130258,0.27577711] |
| 训练 | seed1234，60 epoch，每组从同一ViT-B-16.pt开始 |
| PKM | IMS_PER_BATCH=64，NUM_INSTANCE=4；三模态192图/迭代 |
| 优化器 | Adam，BASE_LR=0.00035，PRETRAINED_LR=0.000005，PE_DELTA_LR_MULT=1 |
| 调度、衰减 | 原cosine、warmup100 iterations、weight_decay=1e-4 |
| 损失 | 原CE+soft Triplet，不开VTC/label smoothing/center loss |
| 增强 | 原Resize、Flip0.5、Pad10、Crop、Normalize、Erasing0.5 |
| 数据线程、测试batch | 8、1024 |
| 日志/评估/保存周期 | 50 iterations / 10 epoch / 60 epoch |
| 最终读出 | epoch60同一权重分别pre-BN/post-BN，FEAT_NORM=yes，RE_RANKING=False |

BNNeck 保持原样：CE读BN后特征，Triplet读BN前特征。pre-BN为主比较，post-BN单列；不从两种读出或多个epoch挑有利结果拼表。

## 5. 结果判断与下一轮

先分别计算候选相对T0和baseline的增益，不把“超过baseline但低于T0”当作改进成功。记录mAP、Rank-1/5/10，以及已有日志中的跨模态和视角分组。若某版本只提高post-BN，应明确限定结论。

不同单卡GPU可并行初筛；小幅领先者最终与T0在同一硬件上确认，并补少量配对seed。GPU型号、实际Runtime、输出目录随结果记录。这属于候选复核，不重开环境/norm对照。依据测试集筛选的结果应保留全部候选并标注探索性筛选。

第二轮优先考虑T1+T4，或T2+T4；只有各自有效后再实现组合。本次配置不包含未验证的组合版。
