既有llmpar的torch/torchvision不配套，本轮不自动升级；以实际192图预检判断兼容。本地CPU/12图或A/B的预检不能替代C服务器预检。失败时保存日志定位，不自动改条件含义、学习率或初始化重试。

## 4. 关键配置和标签核对

| 设置 | 固定值 |
| --- | --- |
| 模型/输入 | CLIP ViT-B/16；256×128；DropPath0.1 |
| 数据 | WHU-MARS/ALL；RGB、IR、Thermal顺序 |
| 标签 | 当前图像内部相机0–6；5/6为Aerial，其余合法0–4为Ground |
| 结构 | METHOD=p3_c；共享1536→32→768预测器，GELU前两类加法条件偏置 |
| 层边界 | block2–12速度全部token，系数1；block3–12预测与创新patch，创新系数0.25 |
| 初始化 | 模块seed1235；双gain、W2/b2和全部条件表为0 |
| 条件参数 | 10×3×32＋10×2×32，共1,600；层间独立；LR1e-4、WD0 |
| 原参数优化 | 主干5e-6，头/gain3.5e-4，Predictor1e-4；原coupled WD保留，创新gain WD0 |
| loss/clip | CE＋原Triplet＋1×十层SmoothL1；任务/预测整体组分别clip1，条件表属于预测组 |
| batch与日程 | seed1234；PKM/K4；逻辑64/实际192图；60epoch cosine，warmup100iterations，起始0.01、最低0.002 |
| 固定评估 | epoch60 post-BN主，同权重pre-BN补充；L2特征、sysu，不rerank |

训练和推理均须提供本图像条件。现有processor已经传入逐图camids；query/gallery使用自己的camidt和模态loader索引。不要根据query/gallery角色替换平台、对camidt再次减1或在推理时置零条件。缺失/非法标签会报错，修复数据/调用来源后再运行，不添加默认Ground回退。
