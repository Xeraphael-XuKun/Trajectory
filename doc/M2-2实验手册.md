# M2-2 跨层状态与修正联合驱动的文本反演

本 worktree 从 `a8349abeb5fb62b5f7d233e33202d1ef1d113b42` 派生，分支为 `codex/m2-b`，代码目录为 `/mnt/cache/wanghanzhi/XK/m2-b/Trajectory`。配置使用 `M2.VARIANT=trajectory_text_inversion`，不叠加旧 TEXT_ALIGN/VTC/VPR。关闭 `M2.ENABLED` 或设为 `none` 时不构造摘要、聚合器、文本塔或 RGB 中心，保留原 C0 路径。

视觉循环在 11 个实际 C0 修正位置保存 `[CLS(H), R_CLS/s, mean(R_patch)/s]` 共 2304 维，状态、修正和尺度均保留梯度。共享 128 维聚合器生成四个伪词，经过冻结文本塔；`clip_proj`、文本塔和 RGB 中心固定，文本输入梯度回到摘要、C0 gain 和视觉 backbone。`ground` 使用 RGB 固定身份中心，`xit` 排除当前光谱且对文本目标 stop-gradient，两个辅助项权重均为 0.5。推理删除摘要与文本分支。

## 工件和启动顺序

`tools/m2/build_clip_cache.py` 遍历 `WHU_MARS.train`，只读取 train 图像并生成含 `features/pids/cams/modalities/platform/pid_map` 及权重/预处理元数据的 CLIP 缓存；随后 `build_rgb_center_cache.py` 进行相机等权聚合并核对字段，拒绝 query/gallery。执行：

```bash
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-b/Trajectory/server/m2_b/preflight.sh
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-b/Trajectory/server/m2_b/build_centers.sh
CUDA_VISIBLE_DEVICES=0 WORLD_SIZE=1 bash /mnt/cache/wanghanzhi/XK/m2-b/Trajectory/server/m2_b/train_student.sh
```

学生脚本以前台方式调用本 worktree 的 `train.py`、`configs/m2_2.yml` 和 llmpar 解释器，输出 `/mnt/cache/wanghanzhi/XK/m2-b/logs/student`。本轮不启动正式训练。训练完成后用同一 epoch60 checkpoint 分别评测 `TEST.NECK_FEAT=after`（post-BN 主结果）和 `before`（pre-BN 补充结果）。
