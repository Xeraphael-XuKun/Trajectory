# M2-2 跨层状态与修正联合驱动的文本反演

代码分支 `codex/m2-b`，共同起点 `a8349abeb5fb62b5f7d233e33202d1ef1d113b42`。服务器隔离目录采用 `/mnt/cache/wanghanzhi/XK/m2-b/Trajectory`；这是本方案的部署约定，本次没有上传代码或确认该目录已存在。

## 固定实验设置

WHU-MARS-1000，train-only RGB 原始 CLIP 教师缓存，真实训练 PID 映射，相机内先平均归一化、相机间等权平均归一化。无 C0 的冻结教师沿用 256×128、CLIP normalize、ln_pre、QuickGELU。主学生从原始 CLIP 开始、C0 gain 零初始化；不从历史 epoch60 续训。RGB/IR/Thermal 分开，PKM 16 ID×每模态4图=192图，未绑定帧或增强。

主训练 60 epoch、seed1234、Adam，backbone 5e-6、新参数 3.5e-4、weight decay 1e-4、100迭代 LR warmup、原调度时钟、视觉 AMP 和一次总损失 backward/全局裁剪 1.0/step。CE 无 smoothing，soft-margin batch-hard Triplet 使用未归一化 pre-BN 特征。M2-2 两辅助权重 0.5、温度 0.07，从第一步启用。宽度128、四伪词、状态/修正/尺度保留梯度；xit 文本目标 detach。没有额外 prompt 阶段，不叠加旧 TEXT_ALIGN/VTC/VPR/GPD/PCA。

配置 `configs/m2_2.yml` 是单份完整配置，可直接使用原入口；测试固定 epoch60、post-BN 为主，同一权重补 pre-BN，L2+平方欧氏、sysu 同相机全排除、不 rerank、不截断 mAP。
