## 2. 唯一结构修改与公式

原P3的真实速度`V_l=block_output_l-actual_corrected_block_input_l`及`Z_l=LN(V_(l-1))`保持；LN沿768通道，非仿射、方差分母768、epsilon1e-5。

在block3–12各增加一个`a_l`，层内形状`[1,1,768]`，总存储`[10,1,1,768]`。按层和通道独立，跨样本、patch、模态和平台共享；全1初始化，无界且可正可负，不是动态图像门控，不使用sigmoid/tanh/softmax或额外正则。

```text
last = sg(Z_(l-1).patch)
old_delta = 0                                      # block3
old_delta = sg(Z_(l-1).patch-Z_(l-2).patch)          # block4–12
U = concat(last, old_delta)
nonlinear = Predictor_l(U)                         # 原1536→32→768，GELU
predicted_state = a_l * last + nonlinear
full_predicted_delta = (a_l - 1) * last + nonlinear
E_l = Z_l.patch - sg(predicted_state)
```

a只改变显式历史预测通路，不乘U、old_delta、当前Z、速度残差或gain。实现分别计算预测状态和完整预测增量，按以上浮点运算顺序使用；二者代数等价于减去/加回last，非整数a时不要求不同运算顺序逐bit相同。

```text
R_l.velocity = velocity_gain_l * Z_l               # block2–12，全129token，系数1
R_l.innovation = 0.25 * innovation_gain_l * LN(E_l) # block3–12，128patch
R_l = R_l.velocity + [0; R_l.innovation]
```

CLS只有速度写入；两支分别归一化/乘gain后相加，不对总残差再LN。两套gain均线性、零初始化；保留原Predictor第一层初始化和第二层权重/bias零初始化，隐藏维度32。没有B的参考方差分母、C的条件输入、P4门控或额外C0。

## 3. 层边界、损失与梯度

| 当前block | 历史与预测 | 写入/监督 |
| --- | --- | --- |
| 1 | 无Z1，不缓存虚构零观察量 | 无写入、无预测loss |
| 2 | Z2来自V1；不调用Predictor | 全token速度写入，缓存真实Z2.patch |
| 3 | 读取Z2，旧增量0；首个a和Predictor | 双支路，首个预测监督层 |
| 4–12 | 最近两条真实Z.patch，历史detach | 双支路、完整预测增量监督 |

历史只在同一次图像前向内存在，最多两条；不缓存预测状态或跨batch历史。当前Z/真实速度保留任务梯度。状态、预测及创新计算继承P3的FP32分支，残差最后转回主干dtype；原block的AMP、attention、MLP和DropPath不改。

预测目标仍为`target=sg(Z_l.patch-last)`。SmoothL1 beta1监督的是完整`full_predicted_delta`，必须包含`(a−1)*last`；不只监督MLP输出、不另加状态损失或a接近1的正则。

每层平均实际图像B×128patch×768通道，再平均block3–12共10层；总loss为原CE＋batch-hard欧氏距离SoftMargin Triplet＋1×L_pred。不开label smoothing，不替换成margin0.3 hinge。

任务组为主干、BNNeck/分类头及两套gain；预测组为全部Predictor和history_retention。任务loss不直接更新a/Predictor；预测loss不直接更新主干或gain。完整预测状态进入E之前detach，E的当前Z路径不detach。a在零输出Predictor、零gain时已有直接预测梯度通路，无需额外warmup。

## 4. 参数量与优化

模块任务参数2,072,832，预测参数752,960。只比原P3多7,680个可训练参数。原Adam及其实际betas/eps保持，不改AdamW；bias学习率系数1。

AMP unscale后，两组各按整体L2总范数1裁剪；不先全模型clip，不逐层裁剪。A的a显式加入预测集合，避免默认“除Predictor外全算任务”的旧实现误分组。Predictor原bias仍WD1e-4，只有新增a免衰减。

固定设置与原P3一致：CLIP ViT-B/16、256×128、DropPath0.1、RGB/IR/Thermal、PKM/K4、逻辑batch64/实际192图、原增强和CLIP norm；训练seed1234/模块seed1235。60epoch cosine、100iteration warmup、起始因子0.01/最低0.002，每10epoch评估，固定epoch60 post-BN主、同权重pre-BN补充，sysu/特征L2归一化、不开reranking。

## 5. 接入、兼容与诊断

`HistoryP3AAdapter`继承原P3，新增a和预测公式；原P3只抽出一个返回“预测增量＋预测状态”的公共方法，保持原p3分支的计算与参数结构。主干block循环、训练入口、数据处理和原loss实现不改。

配置`configs/history_P3_A.yml`显式METHOD=p3_a，外部TOKEN_TRAJECTORY=False。默认METHOD=legacy和原METHOD=p3仍保留。specification的方法标记为113，与原P3的103区分，缺a或规格不符不会静默加载。不能把P3权重直接当A续训权重。

history_epoch.jsonl增加逐层history_retention的mean/min/max/rms_from_one/fraction_negative，记录的是epoch末参数状态；history_gradients.jsonl和history_optimizer_initial.json自动记录a的预测/任务梯度、LR/WD及两组裁剪信息。gain和创新分支诊断继承P3，PG/预测RMS对应完整预测增量。

核心文件：model/backbones/history_p3_a.py、history_p3.py、model/make_model.py、solver/make_optimizer.py、utils/history_training.py、processor/processor.py。检查工具为tools/check_history_p3_a.py、tools/smoke_history_p3_a.py；服务器脚本在server/history_p3_a/sensecore/。

## 6. 本地验证与证据边界

真实CLIP权重和WHU-MARS小批次CPU验证得到P3_A_CHECK_OK：

- a全1时公共参数和RNG与原P3一致；非零双分支及非零Predictor下，完整前向/预测loss逐值复现固定2c71241的原P3。
- 手算非1、含负值的a，确认它只作用显式历史通路，完整预测loss确实包含历史项；首层/第二层边界、CLS范围和两条历史缓存正确。
- 零gain、零预测输出时a已有预测梯度；任务loss对a/Predictor直接梯度为0，预测loss不改变任务组已有梯度。
- 原P3前向/loss/优化规则与2c71241一致；baseline参数、输出与RNG，原P3/C0小公式及旧HI1非零gain前向/loss/优化器兼容检查通过。
- 两次真实CPU Adam更新确认a、两套gain及Predictor启动，预测组752,960参数、LR/WD和整体裁剪归属正确。
- 严格磁盘重载、缺a/错误方法规格拒错、同权重pre/post读出及每次前向清空历史均通过。

本地12图AMP预检16次尝试、7次AMP跳步、9次有效更新，训练峰值显存约2.756GiB，得到P3_A_PREFLIGHT_OK。

本地AMP使用RTX3050 Laptop、Python3.10.20、torch1.13.1+cu117、torchvision0.14.1+cu117、timm1.0.19，复用现有work/check-deps，未安装新依赖。逻辑batch4/K2、同一真实12图batch重复16次；保留60epoch日程与真实sampler iteration尺度。a实际偏离1，任务/预测直接梯度边界、创新启动、分组clip、参数有限性及严格磁盘重载均通过。

证据保存在独立工作树work/p3_a_check/report.json、legacy_report.json和work/p3_a_amp_preflight/preflight_result.json及原始日志。checkpoint、缓存、日志和数据不入Git。局部验证不等于单A800/192图预检，更不等于正式60epoch或性能提升。

## 7. 比较与归档

P3-A仅检验“学习历史基准”的完整路线，不把学习到的a偏离1、预测误差下降或修正活跃当成检索贡献证明。正式仍以原P3为参照，固定epoch60主/辅读出；不增加B/C叠加、参数搜索或额外训练阶段。

本方案、手册及后续结果固定归入`1016_历史创新P3三种改版`批次；文件名带P3-A，保持与B/C和旧P3输出隔离。
