## 2. 真实速度与层边界

公式block号1–12，源码layer为0–11。当前修正前输入为H_l，实际block输入X_l=H_l+R_l，输出H_(l+1)=B_l(X_l)。速度严格取`V_l=H_(l+1)-X_l`，在全部修正写入后保存实际block_input；不使用含适配动作的相邻未修正状态差替代。

`Z_l=LN(V_(l-1))`，沿768通道非仿射LN，epsilon=1e-5。保留当前速度的任务梯度；作为历史使用的patch观察量保存detach副本。历史只在单次前向内存在，最多保留最近三条实际Z，不保存预测值、不跨图像或batch、不读取当前Z作为过去历史。

| 当前block | 观察与历史 | 写入与监督 |
| --- | --- | --- |
| 1 | 无Z1，不缓存虚构零观察量 | R1=0 |
| 2 | Z2；无预测历史，结束缓存Z2.patch | 全129token普通C0，无门控/预测loss |
| 3 | Z3；固定复制Z2.patch，无logits | patch门控，CLS普通C0；无预测loss |
| 4 | Z4；按由近到远读取Z3、Z2，2个logits | patch门控＋预测loss |
| 5–12 | 当前Z；最近三条过去Z，逐层3个logits | patch门控＋预测loss |

状态、历史加权预测、统计与残差乘法用FP32，残差最后转回主干token dtype；原block沿用原AMP、attention、MLP与DropPath。

## 3. 历史先验与三个统计量

block3固定`Z_hat3=sg(Z2.patch)`。block4–12：

```text
pi_l = softmax(theta_l)                  # 每层独立，按历史由近到远
Z_hat_l = sum_k pi_l[k] * sg(Z_(l-k).patch)
E_l = Z_l.patch - sg(Z_hat_l)
```

block4初始权重`[16/19,3/19]`；block5–12为`[0.8,0.15,0.05]`，logits初始化为相应权重的自然对数。权重非负、和为1，不做负权外推，不对加权结果额外LN，没有MLP Predictor、固定投影、Anchor或Corrector。

每个样本/patch计算下列标量，RMS沿768通道，epsilon=1e-6：

```text
c = dot(Z.patch, Z_hat) / (max(norm(Z.patch),eps) * max(norm(Z_hat),eps))
e = tanh(log((RMS(E)+eps) / (RMS(Z.patch)+eps)))
q = tanh(log(1 + RMS(R_previous.patch) / (RMS(H.patch)+eps)))
```

余弦的两个范数分别设置下界。q使用上一层真正写入的patch残差，包括动态乘数和主干dtype转换，detach后保存；不是上一gain范数、未缩放方向或投影动作。

三个统计量整体在`no_grad`中计算。任务损失不经统计生成过程更新当前Z、历史、上一动作或logits；当前Z经C0残差保留任务梯度。

## 4. 轻量门控与C0写入

block3–12每层四个标量`[b,w_c,w_e,w_q]`，全零初始化，在层内跨样本/patch共享；动态输出逐样本/patch变化：

```text
a = b + w_c*sg(c) + w_e*sg(e) + w_q*sg(q)
m = 1 + 0.5*tanh(a)
C_l = velocity_gain_l * Z_l              # block2–12，全token，系数1
R_2 = C_2
R_l.CLS = C_l.CLS                        # block3–12，CLS不乘门控
R_l.patch = m * C_l.patch                # 标量广播到该patch的768通道
```

没有额外0.25系数、第二套dense gain或外部重复C0；配置`MODEL.TOKEN_TRAJECTORY=False`。m在有限实数数学定义下位于(0.5,1.5)，浮点饱和可能取端点。正标量只改变当前C0候选残差幅度；不限制gain本身，不构成整个网络/最终特征的扰动上界，不保证检索收益。

初始C0 gain为零、m=1；第一步门控梯度为零，C0 gain仍正常学习。gain更新后门控启动；没有额外零初始化外部系数阻断启动。

| 参数族 | 形状/分配 | 参数量 | 直接梯度 |
| --- | --- | ---: | --- |
| velocity_gain | `[11,1,129,768]` | 1,089,792 | 身份任务 |
| history_logits | block4为2；block5–12各3 | 26 | 预测loss |
| gate_coefficients | `[10,4]`，block3–12 | 40 | 身份任务 |
| 总新增可训练参数 | 已包含内部C0 | **1,089,858** | 比C0多66 |

按实际分配logits计数，不扣除softmax平移冗余。参数少仍有历史张量、加权预测及统计计算开销。

## 5. 损失、优化和固定设置

`L=CE+Triplet+1*L_pred`，沿用原CE及batch-hard欧氏距离SoftMargin Triplet，不增设label smoothing或hinge margin。预测使用增量形式：

```text
pred_delta = Z_hat_l - sg(Z_(l-1).patch)
target_delta = sg(Z_l.patch - Z_(l-1).patch)
```

SmoothL1 beta=1；每层对实际B×128×768求mean，再平均block4–12共9层。block3复制预测用于门控但不计入loss及分母。历史及目标detach，进入统计的预测detach；预测loss只直接训练logits，任务loss只直接训练主干、头、C0 gain与门控系数。数值前向和后续训练轨迹仍相互影响。

| 参数族 | 峰值LR | coupled WD |
| --- | ---: | ---: |
| CLIP预训练主干 | 5e-6 | 1e-4 |
| BNNeck、分类头 | 3.5e-4 | 1e-4 |
| velocity_gain | 3.5e-4 | 1e-4 |
| history_logits | 3.5e-4 | 0 |
| gate_coefficients（含bias） | 3.5e-4 | 0 |

原Adam及默认betas/eps不变。AMP unscale后，任务参数整体与logits预测参数整体分别按L2总范数1裁剪，不先全模型共同clip。两组不交叠并覆盖全部可训练参数。

统一设置：CLIP ViT-B/16、256×128、12block/768维、DropPath0.1；RGB/IR/Thermal、原PKM/K4、逻辑batch64/实际192图；原增强与CLIP norm。训练seed1234，模块seed1235，fork_rng不改变基础头初始化/全局随机序列。60epoch cosine，100iteration warmup、起始因子0.01、最低因子0.002；每10epoch评估。最终固定epoch60 post-BN为主、同checkpoint pre-BN补充，不挑checkpoint或读出，不开reranking。

`HISTORY.GATE_ETA=0.5`为P4固定门控幅度；`ALPHA=1.0`与all/linear一起约束C0写入。保留的RANK、WRITE_WEIGHT_DECAY属于旧History字段，不控制P4。P4不使用P3的隐藏维度或网络LR字段。

## 6. 已验证证据与限制

真实CLIP权重/WHU-MARS小批次CPU检查得到`P4_CHECK_OK`和`P4_LEGACY_CHECK_OK`：

- 手算三类统计、门控、CLS、历史顺序/先验、block3固定复制和block4监督边界；零向量统计有限，缓存保存真正残差及dtype转换。
- 任务损失不直接训练logits、不经统计回到H或上一动作；当前速度梯度恰等于带detached乘数的C0梯度。预测loss只训练logits。
- 与30eaccc历史backbone、wrapper及优化器对比，baseline/C0参数、固定输入前向和优化规则一致；旧HI1 rank64、非零gain前向/loss/优化器保持一致。
- P4全零gain复现baseline参数/输出/RNG；门控系数为零、C0 gain非零时，CPU/FP32完整训练前向逐值复现原C0。
- 非零gain和门控时用block pre/post hook核对真实速度恰为output-已修正input，且上一动作等于上一实际patch写入；不等于含动作的未修正状态差。
- 9层loss、两次真实CPU Adam更新的gain/门控启动、LR/WD、两组裁剪、严格磁盘重载、eta规格拒错、同权重pre/post读出及前向间状态清空通过。

本地AMP沿用原训练器，RTX3050 Laptop，Python3.10.20、torch1.13.1+cu117、torchvision0.14.1+cu117、timm1.0.19，复用现有依赖，未安装新包。真实12图/2身份，逻辑batch4/K2，同一batch重复16次尝试，7次初期AMP跳步、9次实际更新，得到`P4_PREFLIGHT_OK`；训练峰值显存约2.571GiB。

AMP核对logits任务梯度为0、预测loss对gain/门控系数直接梯度为0，gain和门控均启动、历史权重更新、block2无门控，分组clip及严格磁盘重载一致、参数有限。初期非有限诊断以null记录，不把跳步算更新。保持60epoch日程和真实sampler iteration尺度；短循环文件transformer_1.pth不是完整epoch1结果。

证据位于独立工作树`work/p4_check/report.json`、`legacy_report.json`及`work/p4_amp_preflight/preflight_result.json`和对应原始日志；产物不加入Git。服务器脚本通过Bash语法检查。当前没有P4正式检索结果；本地12图检查不能替代单A800/192图预检或60epoch训练。
