## 1. 研究背景、已有 C0 与固定边界

任务为 WHU-MARS-1000 上的 Any-Scenario Person Re-Identification（AS-ReID）：同一模型面对RGB、IR、Thermal及空地视角，主协议为ALL混合gallery检索。CLIP ViT-B/16作为视觉主干。已有baseline使用原身份CE和Triplet；早期Trajectory扩展中的速度版本C0在pre/post都表现较好，暂时作为模块一参照。

此前尝试过为C0附加辅助约束等模块二，结果不足以替代C0。本阶段没有把这些后续模块二迁入新目录。仓库仍可能保留早期迁移的关闭代码，它们不是当前方案的组成部分，也不能当成新方法来源。

我们选择先单独测试 baseline＋老师的新方案，而不是强行给C0叠加新方案。二者都在Transformer block之前根据深度演化信息写入修正，操作位置和作用对象重合；目前将新方案视为模块一的替代候选更合理。是否最后重新组合，取决于独立证据。

### 1.1 真实 C0 计算，不要与旧 T0 加速度版混淆

设第l个原block为B_l。C0在第1个block不写入，从第2—12个block前写入。上一block的速度为其输出减去**已经加过修正的block输入**：

$$
V_{l-1}=B_{l-1}(H_{l-1}+R_{l-1})-(H_{l-1}+R_{l-1}),\qquad
R_l=G_l\odot\operatorname{LN}(V_{l-1}).
$$

C0的`TOKEN_TRAJECTORY_ACCEL_MIX=0.0`只关闭加速度项，**没有关闭Trajectory**。它修正CLS＋全部128个patch；gain无界、零初始化，形状`[11,1,129,768]`，新增1,089,792参数。原实现中velocity不detach，跨层身份梯度保留。方向直接来自主干产生的速度，经非仿射LayerNorm归一化；没有另一个学习方向的Anchor/Corrector/Predictor，也没有额外辅助损失。

这些区别很重要：新方法同时改变了“用什么历史”“是否detach”“方向如何生成”“方向幅度是否归一化”“哪些层写入”和参数量。因此，完整新方法与C0的性能差不能只归因于创新量或gain边界。

| 对比项 | 历史 C0 | 初始完整新方案 HI1 |
| --- | --- | --- |
| 历史量 | 先前block内的实际更新速度 | 先前block前、修正前的归一化投影状态 |
| 历史梯度 | velocity不detach | 历史状态/先前修正均detach |
| 方向 | LN(速度) | 学习的Anchor(E)＋Corrector(S,E,先前修正) |
| 方向幅度 | 速度经LN | D未做输出LN或范数约束 |
| 写入层 | block2—12 | block1—12 |
| token | CLS＋patch | patch；HI2/HF3扩展CLS |
| gain | G | 0.25·tanh(G)；HI3/HD/HF改线性 |
| 辅助目标 | 无 | 预测当前投影状态增量，λ=1 |
| 新增参数 | 1,089,792 | 2,653,312；CLS版本2,662,528 |

原文的核心假设是：同一图像跨深度的变化存在可预测部分，当前状态与历史预测之间的创新量能帮助生成适应性修正，配合身份监督改善检索。原文并没有证明“预测更准确必然提升ReID”，也没有证明“固定P使不同层语义完全对齐”。

`tanh(G)`有界只限制gain，不限制学习方向D的范数，所以整个修正R仍可能很大。α=0.25、rank64、λ=1在本项目是首轮预设，不是已经搜索出的最优设置。

## 3. 本项目的精确实现

### 3.1 输入、层号与缓存时机

图像256×128，ViT-B/16得到128个patch＋1个CLS，每个token维度768，12个block。本文公式l从1开始；源码`layer/i`从0开始。H_l是**本层修正之前**的block输入，S_l也在本层写入前计算。历史缓存不是跨图像/跨iteration记忆。

固定P为768×64，随机矩阵QR分解得到正交列，`P^T P≈I`；P是buffer随checkpoint保存，各层共用，不可训练。状态LN为`F.layer_norm(tokens,(768,))`，无learnable affine，默认eps=1e-5。

### 3.2 patch路径公式

`sg`表示停止梯度，`[;]`表示通道拼接：

$$
S_l=\operatorname{LN}(H_l^{patch})P,
\quad \Delta_{l-1}=\operatorname{sg}(S_{l-1})-\operatorname{sg}(S_{l-2}),
$$

$$
\widehat\Delta_l=\Pi_l([\operatorname{sg}(S_{l-1});\Delta_{l-1}]),
\qquad E_l=S_l-(\operatorname{sg}(S_{l-1})+\widehat\Delta_l),
$$

$$
Q_{l-1}=\operatorname{sg}(R_{l-1}^{patch})P,
\qquad D_l=W_{e,l}E_l+F_l([S_l;E_l;Q_{l-1}]),
$$

$$
R_l^{patch}=\alpha f(G_l)\odot D_l,\qquad
H_{l+1}=B_l(H_l+[0;R_l^{patch}]).
$$

- 首层无预测器调用，E_1=S_1，Q_0=0；首层仍允许写入。
- 第2层只有一条历史，old_delta=0。之后用最近两条状态，旧条目丢弃。
- 第l层结束前缓存本层**修正前**S_l.detach，以及已经转换到主流dtype的实际R_l.detach()再投影；Q没有额外LayerNorm。
- Predictor为128→64→64的Linear/GELU/Linear，各层独立，共11个；Anchor为64→768无bias；Corrector为192→64→768的Linear/GELU/Linear，共12套。
- G形状`[12,1,128,768]`，零初始化，按层/token/channel学习但在batch内共享；G本身不是每图预测的动态门控，D由图像决定。
- f为tanh或identity，见实验矩阵。方向D没有额外归一化。
- 小型状态/预测/方向计算在禁用autocast的FP32执行，r转回h.dtype后加到主干；原block仍使用原AMP，不重写attention/MLP。

新增参数分解：patch gain 1,179,648，Predictor 136,576，Anchor 589,824，Corrector 747,264，总2,653,312。CLS版本仅增加9,216个gain，网络与P共享，总2,662,528。固定P不计入可训练参数。

### 3.3 CLS扩展不是简单复制patch均值

HI2/HF3为CLS单独保留其S、旧状态、预测创新量和先前CLS修正，使用相同每层网络逐token处理，并增加独立CLS gain。没有用patch修正均值去替代CLS。为保持对照，**所有版本预测loss只监督patch，不增加CLS预测目标或改变分母**。因此CLS方向受到共享网络的patch预测监督影响，但CLS没有自己的直接预测辅助loss。

### 3.4 实际损失与梯度路径

$$
L_{pred}=\frac1{11}\sum_{l=2}^{12}\operatorname{SmoothL1}_{\beta=1}
(\widehat\Delta_l,\operatorname{sg}(S_l-\operatorname{sg}(S_{l-1}))),
$$

$$
L=L_{CE}+L_{Triplet}+\lambda_{pred}L_{pred}.
$$

先对batch/128patch/64channel求mean，再对11层求mean。每个iteration计算全部第2—12层，**不是轮换检查**；没有新增参考分支或额外完整主干forward。λ=1的组从epoch1启用，没有旧C方案的epoch6 warmup。λ=0仅不把loss加入训练目标，仍计算并记录原始预测loss，Predictor仍在forward并能经身份目标更新。

| 路径 | 身份loss直接梯度 | 预测loss直接梯度 |
| --- | --- | --- |
| 主干当前H/S | 有，经后续任务输出 | 无，历史输入和目标detach |
| Predictor | 有，经E→D→r；gain为零时被挡住 | 有，λ>0时 |
| gain/CLS gain | 有 | 无 |
| Anchor/Corrector | 有，但gain=0时初始为零 | 无 |
| 历史缓存S/先前r | 停止跨缓存反传；主干正常主路径仍保留 | 无 |
| 固定P | 不可训练 | 不可训练 |

注意，“没有直接预测梯度”不代表完全互不影响：共享参数会改变未来forward，预测梯度参与全模型clip也可改变其他参数的缩放。当前状态保留身份梯度，Predictor不是与任务完全隔离的纯统计预测器。

零gain使初始化函数与baseline相同，但也造成初始身份梯度先到gain、方向网络暂时被挡住。**方向网络仍有非零随机权重并受Adam衰减**；这一组合后来成为追因重点。零gain不等于整个训练过程与baseline相同。

## 6. 第一阶段 HI：完整方案与初始对照

### 6.1 实验定义

### 6.3 追因一：不是看到“linear更高”就证明tanh限制了模型

HF2的Predictor参数/输出接近零，行为接近“复制上层状态＋当前内容修正”；仍然保留历史输入和可学习网络。它的Rank-1反而较好，提示“精确预测器必要性”尚未成立，而不是已经证明预测毫无价值。

### 8.5 不是换pre-BN或挑早期checkpoint就能解释失败

HF四组pre与post相对C0都较差。训练用的CE/Triplet与BN角色没有因TEST.NECK_FEAT而改变。不能归因为“将post设为主读出导致训练变差”。

有些组Rank-1在epoch30更高，后面回落；但四组mAP在六次周期评估中均以epoch60最高。没有同时改善mAP/Rank的早停证据，也没有依据自动延长训练来补救。当前仍按既定epoch60报告，不挑各指标各自最好checkpoint。

## 10. 已做的实现检查，以及检查不能证明什么

### 10.1 已有局部源码/CPU/GPU检查

- 关闭History时，与独立起点baseline参数及固定随机输入输出一致；C0非零gain路径与历史实现一致。
- History零gain时baseline/head初始化、输出及初始化后的RNG一致；新模块使用独立fork_rng初始化。
- 手算核心公式与模块输出一致；P正交；仅patch写入；历史状态和上层残差缓存detach；历史不跨图像泄漏。
- 辅助loss直接更新Predictor；gain由身份梯度启动；更新gain后方向网络和Predictor身份梯度可达。
- HI1重构前后非零gain逐值一致；HI1/HI3零点输出和初始gain梯度一致；HI3保留0.25；CLS使用自己历史而非patch均值。
- checkpoint保存P/推理规格/新参数，加载后局部输出一致；post/pre来自原读出。
- 原训练入口四组本地12图GPU smoke各16次尝试、7次AMP跳步、9次实际更新，磁盘重载一致。这不是A800/192图正式结果。
- WD覆盖仅作用指定写入族；History关闭时不会套用新分组；HI原分组保持。加入梯度诊断前后CPU连续3次Adam更新一致；本地GPU24次尝试/8跳步/16更新的完整state_dict一致。

这是“没有在这些检查范围内发现使实验失效的错误”，不是“代码已经被完全证明正确”，也不是“方法一定有效”。局部smoke使用Python3.10/torch1.13.1，与正式服务器环境不同。详见doc28—32和对应工具输出。

```python
"""History-conditioned innovation adaptation; PDF pp. 5, 8-9, 13-14.

History is local to one image forward. This replaces, rather than stacks with,
Trajectory. The original ViT block itself is never reimplemented here.
"""
import torch
from torch import nn
from torch.nn import functional as F


class HistoryInnovationAdapter(nn.Module):
    def __init__(self, dim, depth, patches, rank=64, alpha=0.25,
                 prediction_layers=None, token_scope='patch', gain_mode='tanh'):
        super().__init__()
        if not 0 < rank <= dim or depth < 2 or alpha <= 0:
            raise ValueError('Invalid history rank, depth or alpha')
        if token_scope not in ('patch', 'all') or gain_mode not in ('tanh', 'linear'):
            raise ValueError('Unknown history token scope or gain mode')
        self.token_scope = token_scope
        self.gain_mode = gain_mode
        self.depth = depth
        self.alpha = float(alpha)
        # Public layer numbers are 1-based; layer 1 has no prediction target.
        layers = list(range(2, depth + 1)) if prediction_layers is None else list(prediction_layers)
        if not layers or len(set(layers)) != len(layers) or any(l < 2 or l > depth for l in layers):
            raise ValueError('PREDICTION_LAYERS must be distinct layers in [2, depth]')
        self.prediction_layers = frozenset(layers)
        q, _ = torch.linalg.qr(torch.randn(dim, rank), mode='reduced')
        self.register_buffer('coordinate', q)
        # Detect wrong inference alpha / shape on disk reload, not just tensor sizes.
        # Preserve the original HI0/HI1 signature; other formulas require new metadata.
        spec = [1, dim, depth, patches, rank, alpha]
        if token_scope != 'patch' or gain_mode != 'tanh':
            spec = [2, dim, depth, patches, rank, alpha,
                    int(token_scope == 'all'), int(gain_mode == 'linear')]
        self.register_buffer('specification', torch.tensor(spec))
        self.gain = nn.Parameter(torch.zeros(depth, 1, patches, dim))
        # Extra zero rows consume no RNG; shared predictor / direction weights stay matched.
        self.cls_gain = nn.Parameter(torch.zeros(depth, 1, 1, dim)) if token_scope == 'all' else None
        # No unused predictor for the first layer.
        self.predictors = nn.ModuleList([
            nn.Sequential(nn.Linear(2 * rank, rank), nn.GELU(), nn.Linear(rank, rank))
            for _ in range(depth - 1)])
        self.anchors = nn.ModuleList([nn.Linear(rank, dim, bias=False) for _ in range(depth)])
        self.correctors = nn.ModuleList([
            nn.Sequential(nn.Linear(3 * rank, rank), nn.GELU(), nn.Linear(rank, dim))
            for _ in range(depth)])


    def _token_update(self, tokens, gain, layer, history, previous_r):
        s = F.layer_norm(tokens, (tokens.shape[-1],)) @ self.coordinate
        prediction = target = None
        if history:
            last = history[-1]
            old_delta = last - history[-2] if len(history) > 1 else torch.zeros_like(last)
            prediction = self.predictors[layer - 1](torch.cat((last, old_delta), -1))
            innovation = s - (last + prediction)
            target = (s - last).detach()
        else:
            innovation = s
        previous = torch.zeros_like(s) if previous_r is None else previous_r
        direction = self.anchors[layer](innovation)
        direction = direction + self.correctors[layer](torch.cat((s, innovation, previous), -1))
        effective_gain = gain.tanh() if self.gain_mode == 'tanh' else gain
        residual = self.alpha * effective_gain * direction
        return residual, s, innovation, prediction, target

    def correction(self, h, layer, history, previous_r, collect=False, diagnostics=False):
        with torch.autocast(device_type=h.device.type, enabled=False):
            patches = h[:, 1:].float()
            if patches.shape[1:] != self.gain.shape[2:]:
                raise ValueError('History adapter requires its configured patch grid')
            all_tokens = self.token_scope == 'all'
            patch_history = [v[:, 1:] for v in history] if all_tokens else history
            patch_previous = previous_r[:, 1:] if all_tokens and previous_r is not None else previous_r
            patch_r, s, innovation, prediction, target = self._token_update(
                patches, self.gain[layer], layer, patch_history, patch_previous)
            if all_tokens:
                # Independent CLS history, same per-token networks. Never pool patch updates.
                cls_previous = None if previous_r is None else previous_r[:, :1]
                cls_r, cls_s, _, _, _ = self._token_update(
                    h[:, :1].float(), self.cls_gain[layer], layer,
                    [v[:, :1] for v in history], cls_previous)
                r = torch.cat((cls_r.to(h.dtype), patch_r.to(h.dtype)), 1)
                current_state = torch.cat((cls_s, s), 1)
                next_r = r.detach().float() @ self.coordinate
            else:
                r = torch.cat((torch.zeros_like(h[:, :1]), patch_r.to(h.dtype)), 1)
                current_state = s
                next_r = r[:, 1:].detach().float() @ self.coordinate
            next_history = (history + [current_state.detach()])[-2:]
            item = None
            if collect:
                # ALL variants supervise patches only, with identical loss denominator.
                item = {'prediction': prediction, 'target': target}
                if diagnostics:
                    with torch.no_grad():
                        stats = {
                            'state_variance': s.var(-1, unbiased=False).mean(),
                            'innovation_rms': innovation.square().mean().sqrt(),
                            'correction_rms': patch_r.square().mean().sqrt(),
                            'correction_ratio': patch_r.square().mean().sqrt() / patches.square().mean().sqrt().clamp_min(1e-8),
                        }
                        if all_tokens:
                            stats.update(cls_correction_rms=cls_r.square().mean().sqrt(),
                                         cls_correction_ratio=cls_r.square().mean().sqrt() / h[:, :1].float().square().mean().sqrt().clamp_min(1e-8))
                        if prediction is not None:
                            stats.update(prediction_mse=(prediction - target).square().mean(),
                                         copy_mse=target.square().mean(),
                                         prediction_rms=prediction.square().mean().sqrt(),
                                         target_rms=target.square().mean().sqrt())
                        item['diagnostics'] = stats
        return r, next_history, next_r, item

    @torch.no_grad()
    def gain_diagnostics(self):
        result = {}
        for name, gain in [('patch', self.gain), ('cls', self.cls_gain)]:
            if gain is None:
                continue
            values = gain.detach().float().flatten()
            absolute = values.abs()
            quantiles = torch.quantile(absolute, absolute.new_tensor([0.5, 0.95, 0.99]))
            effective = self.alpha * (values.tanh() if self.gain_mode == 'tanh' else values)
            result[name] = {
                'rms': float(values.square().mean().sqrt()),
                'abs_p50': float(quantiles[0]), 'abs_p95': float(quantiles[1]),
                'abs_p99': float(quantiles[2]), 'abs_max': float(absolute.max()),
                'fraction_abs_gt_1': float((absolute > 1).float().mean()),
                'fraction_abs_gt_2': float((absolute > 2).float().mean()),
                'effective_abs_max': float(effective.abs().max()),
                'mean_gain_derivative': float(self.alpha * (1 - values.tanh().square()).mean()) if self.gain_mode == 'tanh' else self.alpha,
            }
        return result
```

```python
"""Detached-target increment prediction loss, PDF Eq. (20)."""
import torch
from torch.nn import functional as F


def history_prediction_loss(aux):
    terms = [F.smooth_l1_loss(aux['layers'][l]['prediction'].float(),
                            aux['layers'][l]['target'].float(), reduction='mean', beta=1.0)
             for l in aux['prediction_layers']]
    return torch.stack(terms).mean()


@torch.no_grad()
def history_diagnostics(aux):
    # Called only on logged batches. PG is a ratio of batch MSEs, not retrieval.
    result = {}
    for layer, item in aux['layers'].items():
        values = item.get('diagnostics', {})
        result[str(layer)] = {k: float(v) for k, v in values.items()}
        if 'copy_mse' in values:
            result[str(layer)]['prediction_gain'] = float(
                1.0 - values['prediction_mse'] / values['copy_mse'].clamp_min(1e-8))
    return result
```
