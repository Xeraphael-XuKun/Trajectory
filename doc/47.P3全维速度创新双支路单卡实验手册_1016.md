## 4. 关键配置核对

| 项目 | P3定义 |
| --- | --- |
| 模块 | HISTORY.ENABLED=True、METHOD=p3；MODEL.TOKEN_TRAJECTORY=False，避免重复C0 |
| 原block速度 | output-已加完整修正的实际input，保留当前速度任务梯度 |
| 观察量 | LN(V)，全部129token、768维；无固定投影 |
| 速度分支 | block2–12、CLS＋patch、线性零gain、系数1 |
| 创新分支 | block3–12、patch-only、线性零gain、系数0.25 |
| Predictor | 1536→32→768、10套，末层零初始化；输入历史、目标及任务参照detach |
| 创新方向 | 对各自归一化速度形成预测残差后，再LN(E)；不对双分支总残差做LN |
| loss | 原CE＋SoftMargin Triplet＋1×10层SmoothL1，单层平均B×128×768 |
| LR | 主干5e-6；头及两类gain3.5e-4；Predictor1e-4 |
| WD | 主干/头/velocity_gain/Predictor为1e-4；innovation_gain为0 |
| clip | AMP unscale后，任务组整体1、预测组整体1，不先共同全模型clip |
| batch/采样 | 原PKM/K4，逻辑64、实际192图，RGB/IR/Thermal |
| 图像/主干 | 256×128、CLIP ViT-B/16、DropPath0.1；原CLIP norm与增强 |
| 日程/seed | 60epoch cosine；100iteration warmup、起始0.01、最低0.002；训练1234、模块1235 |
| 评估 | 每10epoch，最终epoch60 post-BN为主、同权重pre-BN补充，不开reranking |

不要将HISTORY.ALPHA=0.25误用于速度路径。TOKEN_SCOPE=all只描述速度范围，创新仍patch-only。resolved配置的RANK/WRITE_WEIGHT_DECAY是旧History保留字段；P3用PREDICTOR_HIDDEN_DIM=32和明确的gain分组。
